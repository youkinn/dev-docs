## 3. 阈值假设（**未验证**，我自己定的经验值）

用途：判「是否异常」时先有个抓手；被实测推翻就改，验证充分后再考虑固化进手册。

| 读数 | 假设阈值 | 含义 | 状态 |
|------|----------|------|------|
| `queueWait` | > 1 s | 排队异常（并发 / 前序请求卡住） | 未验证 |
| `tool` | > 1 s | MCP 侧异常（基线 60–100 ms） | 未验证 |
| 单轮 `llm` | > 8 s | 模型侧异常或截断重试 | 未验证 |
| `server − queueWait − llm − tool` | > 500 ms | 总台自身开销异常（拼接 / 序列化） | 未验证 |
| `cachedTokens / promptTokens` | < 0.5 | 提示词缓存失效（前缀变动） | 未验证 |
| `finishReason` | `length` | 输出被 `max_tokens` 截断（思考吃满 → 空答案，bug-00018） | 依据充分 |
| 同 `stage` 的 `seq` 条数 | > 1 | 发生重试 | 依据充分 |
| `nextRank.gapToTopN` | < 0.001 | 排序脆弱（第 N+1 名几乎同分） | 未验证 |
| `funnel.injected` vs `topN` | 差值 ≥ 1 | 注入视图截断 | 依据充分（A009 口径） |
| `env.degradedBm25Only` | `true` | 向量路降级（召回质量下降的环境根因） | 依据充分 |
