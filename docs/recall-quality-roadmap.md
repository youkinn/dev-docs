## 0. 课题目标与判据（北极星）

精准召回、不漏召。判据**必须同时满足**，防止「召回率上升、答案质量下降」的空转：

- 检索侧：标准集（§2 重建后）bestRank top≤5 由 78.1% 提升；目标值在标准集重建后重定。
- 答案侧：top5 相关度不倒退 + 拒答正确率（该答没答 / 不该答却答均算违例）。
- 评测执行口径：**批量 LLM 测评由负责人抽样执行，程序不批量跑**（token 控制，AGENTS.md 规则 4 的延伸口径）。

## 2. 标准集（D1）组织方式

- 类型清单（初版，待负责人审定）：人物称谓、地名、战役、典故成语、器物、身体部位、官职、数字称谓、事件关系（主宾反转类）、死亡类、拒答类（原文确无）。
- 每类 5–10 问：人工审定——原文确有答案、问法自然、覆盖「鸿沟写法」（同实体不同写法 / 换说法 / 差一字变体）。
- 判定沿用 recall-bench 口径（正则 → 正确答案段），答案层补「结论支撑」判定（bug-00008）。
- 验收：负责人抽样；程序不批量跑 LLM。

## 3. 执行顺序

- **T0（并行启动）**：T0-a 草稿台（CLI 先行，页面版随后）｜ T0-b 标准集重建（负责人审定 + Coco 脚本）｜ T0-c 温度按域实验（并入草稿台）。
- **T1（依赖标准集作为测量）**：T1-a 归一化/换说法统计脚本 + 双表落地（新特性号，D11）｜ T1-b query 改写（D4）｜ T1-c0 池覆盖探针（证据段入 50 路池覆盖率 + recall-bench 当前基线，零 LLM，前置）｜ T1-c 重排模型调查（D2，批量评测按 §0 口径放行+抽样）｜ T1-d 意图判定轻量 LLM 评估（D8）。
- **T3（视 T0 结论）**：注入叙事序生产化与否（D6）｜ 注入截断统计与预算评估（D7）。

分工：检索/重排/意图（老陈）｜ 编排/注入/温度/草稿台后端（小胡）｜ 草稿台前端/观测（小叶）｜ 统计脚本/标准集/路线图（Coco）｜ 验收与抽样（负责人）。
