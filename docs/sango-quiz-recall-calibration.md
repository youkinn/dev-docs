> 关联：bug-00022（并列候选答非所问）、bug-00021（未收录被先验知识答）、`requirements/BACKLOG.md` BL-019（向量召回）

## 1. 为什么需要它

负责人做「顺序打乱」扰动测试时暴露：当前**判对判错全部由字面重合决定**（字符 bigram Dice），语义判定没有参与。要重做召回，先得定「什么算对」，否则改完仍无法验收。

## 2. 扰动分类与期望口径（待负责人确认）

| 类别 | 例子 | 期望口径（草案） | 判据 |
|------|------|------------------|------|
| 原题 | 诸葛亮发明的运输工具是？ | 答答案原文 | 字面 1.0 |
| 换说法 | 刘备靠什么过活 ↔ 刘备最初是靠什么谋生的？ | 答答案原文 | 含义相同 |
| 字序打乱（仍是问句） | 暂无样本 | 待定 | — |
| 字序打乱（非问句） | 运输工具骑着诸葛亮的是发明 | 待定（倾向「未收录」） | 语义不可判定 |
| 实体互换（答案不变） | 董卓通过貂蝉使用什么计策离间吕布与王允？ | 答答案原文 | 含义相同、答案不变 |
| 实体互换（答案改变） | 暂无样本 | 答该实体对应的答案 | 需按实体定位 |
| 错字 / 漏字 | 关于字什么（关羽 → 关于） | 待定（倾向「未收录」） | 语义不可判定 |
| 同模板不同实体 | 刘备的字是什么？（题库无此题） | 未收录话术 | 候选无含义对应 |
| 完全无关 | 今天天气怎么样 | 未收录话术 | 无候选 |

## 4. 待补（大改验收的前提）

1. 每类扰动的**样本量与期望答案**（建议每类 ≥ 10 条），形成可跑的固定问句集。
2. **通过率门槛**（如「换说法类 ≥ 90%；未收录类 100% 不得误答」）。
3. 判据要**可复算**：落 score / 命中依据，复用 feat-A009 诊断口径。

## 5. 与需求的关系

本文件是**验收材料**，不是需求文档。大改立项后，验收标准（标定集通过率）写进需求文档，本文件作为其判据与样本来源。
