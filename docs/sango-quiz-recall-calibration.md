## 1. 为什么需要它

负责人做「顺序打乱」扰动测试时暴露：当前**判对判错全部由字面重合决定**（字符 bigram Dice），语义判定没有参与。要重做召回，先得定「什么算对」，否则改完仍无法验收。

### 2.1 恒真样本：保字面扰动（不得计入通过率）

负责人实测主张（2026-09-23）：对**所有**题目，只要把主谓宾顺序替换，**不论语义通不通都能拿到正确答案**。Coco 全量复核（88 题，按 2 字块倒序模拟词序置换）：

| 指标 | 读数 |
|------|------|
| top1 命中原题 | **88 / 88** |
| 最低 top1 dice | 0.500 |
| 最小 top1 − top2 间距 | 0.067 |

样例：`王允通过貂蝉使用什么计策离间吕布董卓？` → 倒序 `董卓吕布离间计策什么使用貂蝉通过王允` → 仍命中原题。

**机制**：Dice 是**字符 bigram 集合**运算，对词序天然不敏感；只要词块内部相邻关系保留，重合度几乎不变 → **恒真**。

**结论（方法论，重要）**：

- 这类样本**不得计入通过率**。它验证的只是「实现是 bag-of-bigrams」——同族实现都会全绿，**没有判别力**（召回改不改都看不出来）。
- 它唯一的价值是**反证**：证明当前「答对」与语义理解无关。
- 有判别力的样本只有两类：**破字面扰动**（换说法 / 错字漏字 / 同模板不同实体 / 完全无关）与**保字面但含义变**（角色反转 / 前提错误）。

> `fa657317` 说明（2026-09-23 改判，负责人指出）：原著是**王允**用貂蝉行美人计 / 连环计，离间**吕布与董卓** —— 董卓是被离间的一方，不是用计的人。乱序句「董卓通过貂蝉使用什么计策离间吕布与王允」**把施动者与对象都反了**，是**错误前提**，不是「答案不变的实体互换」。
> 系统按字面 0.857 命中原题、照答「美人计」：答案**碰巧**与用户所问的槽位（什么计策）相同，但**没有纠正前提** —— 用户会误以为「是董卓用计」。
> 故本条**不是正例**：它暴露的是「题库域只输出答案原文、不做任何前提校验」这一设计边界，期望行为需求未定义（见第 4 节）。

> 按判别力分类（2026-09-23）：`a5232947` 破字面（同模板不同实体）；`9b2825f3` 破字面（错字）；`fa657317` 保字面但含义变（角色反转）；`223eb61e` **恒真样本**（不计分，仅作反证）。

## 4. 待补（大改验收的前提）

1. 每类扰动的**样本量与期望答案**（建议每类 ≥ 10 条），形成可跑的固定问句集。
2. **通过率门槛**（如「换说法类 ≥ 90%；未收录类 100% 不得误答」）。
3. 判据要**可复算**：落 score / 命中依据，复用 feat-A009 诊断口径。
4. **错误前提类要不要纠正**（施动者 / 对象反转，如 `fa657317`）：照答答案会误导用户，纠正前提又超出「只输出答案原文」契约 → 属产品口径，需负责人定（若要纠正，是**新能力**，应另立特性，不塞进召回重做）。
5. **标定集按判别力重构**：只收「破字面扰动」与「保字面但含义变」两类，明确剔除恒真样本（§2.1）。
