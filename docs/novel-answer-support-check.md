# 演义域回答-片段支撑校验（长期机制）设计：复核轮 + 封闭结构保险丝

> 类型：技术方案（决策与理由 / 契约 / 风险 / 验证，不写流水账）
> 关联：bug-00028（凭先验作答 + 引用不支撑）、feat-A004（拒答红线）、feat-A006（引用结构化）、feat-A011（提示词瘦身）、feat-A013（缓存）
> 作者：Coco ／ 日期：2026-09-24 ／ 状态：定稿（Coco 定案，技术取舍见正文；成本口径已向负责人报备）

## 问题与目标

- 问题 A（语义）：演义域生成轮凭先验作答——注入片段不支撑结论仍答出史实，并挂不支撑引用（马超 / 夏侯渊 / 刘备三例）。提示词约束在、模型不服从（bug-00028 主因）。
- 问题 B（机制）：纯规则语义裁决不可维护——死亡 / 数值 / 表字信号是词表型判定，新问法就要加词表，最终堆成不可维护的规则墙（负责人定性）。
- 目标：语义裁决交给 LLM 复核轮（新问法零维护）；规则层收缩为**问法无关的封闭结构不变量**；硬规矩「规则只减不增」。

## 决策与理由（备选 → 为什么选它）

1. **复核轮承接语义裁决**（新增编排 stage，演义域生成轮后、写日志与写缓存前执行）。
   - 备选：同轮自检（生成时要求先给支撑再作答）→ 同模型同上下文，正是「约束在、模型不服从」的失败面本身，否决。
   - 备选：词表规则扩充 → 随问法膨胀不可维护，负责人已否决。
   - 代价：每次演义域生成 +1 次小模型复核调用（输入 ≈ 注入片段 + 答案；输出为短 JSON）；缓存命中路径跳过；延迟与 token 增加，负责人知情接受。
2. **保险丝 = 维持现有两条结构门，本票不新增任何规则**。
   - 保留（任何问法下都必须成立、不会因新问法增长）：
     - 引用指针必须指向本次注入的片段（`validateQuotePointers`，已有）；
     - 答案断言人物 ⊆ 召回人物（`verifyCitation`，已有，保持全量口径）。
   - 不新增第三条门：无合法指针的事实性回答已由既有兜底路径（`concludeFallback` 重建答案 + 恰一条兜底引用，A006 定稿行为）覆盖，无需新规则。
   - 移除（归复核轮职责）：死亡证据词表、数值同值判定、表字值判定。
   - 硬规矩：**规则表只减不增**；任何「新增语义规则」的诉求 = 报警信号 → 转复核轮提示词 / 增强 + 架构评审。
3. **复核轮判定契约**：
   - 输入：**用户问题** + 注入片段全文（前 5 段保底 + 预算内段，同生成轮视图）+ 模型答案 + 引用指针清单。
   - 输出（仅 JSON）：`{ citations: [{ pointer, support: supported|unsupported|uncertain }], overall: supported|unsupported|uncertain }`。
   - 判定对象 = 「答案对用户问题的回答」：须正面回答该问题且引用片段语义支撑才判 `supported`；**答非所问**（未触及问题核心，如问结局答过程）判 `unsupported`。
   - 动作映射：
     - `overall=unsupported` → 拒答：正文「演义中未涉及」+ 清空引用（A004 红线，宁拒勿猜）；
     - 部分支撑 → 仅保留 `supported` 引用，指针重编号，`citations` 与 `funnel.cited` 回填；
     - `uncertain` → 按 `unsupported` 处理（宁拒勿猜；观测分布后调整，不新增规则）。
   - 解析失败（非 JSON / 字段缺失）→ 重试 1 次 → 仍失败按 `unsupported` 拒答（宁拒勿猜；A006 要求答案必带引用，「去引用保留答案」破坏响应形态，否决）。解析失败计数记入日志供观测解析率。
   - 复核轮 LLM 调用异常（网络 / 限流 / 超时）沿生成轮既有口径向 server 上抛（不隐式拒答——「演义中未涉及」只表「原文未涉及」，不表系统故障，口径不可混淆）。
   - `overall=supported` 但逐条判定无任何 `supported` 引用留存（模型自相矛盾）→ 按 `kept=0` 拒答（口径延伸）。
4. **日志契约（A007）**：`llm_call_logs` 新增 `stage=novel_support_check`（复用现有表结构，不新增字段）；`request_logs` 无需新字段（`answer` / `citations` 已承载结果）；同步 `docs/troubleshooting.md` 维护记录。
5. **缓存（A013）**：复核轮后写缓存（拒答类不写缓存规则不变）；缓存命中跳过生成 + 复核（缓存内容即复核后答案）。

## 风险 & 已知约束

- 复核轮本身可能判错：主裁错误由「宁拒勿猜」吸收（误拒多、误放少）；观测点 = 复核轮判定分布 + 拒答率趋势（日志页），不靠堆规则。
- 成本：+1 次小模型调用 / 演义域请求（非批量，属常驻路径，已向负责人报备口径）。
- 不涉及：检索 / 注入预算 / 权重 / A011 提示词正文 / mcp-server 出参契约，均不动。

## 验证（可判定）

1. 三例回归 + 问法变体（例：「马超后来咋样了」「马超投奔刘备后的结局」「刘备死时多大」）均拒答或仅留支撑引用。
2. 正例不误伤：表字正例（元让在片段）、数值同值正例（55 ↔ 年五十五）、纯叙述放行（控制组）。
3. 复核轮输出契约单测（JSON 解析 / 字段缺失熔断 / 各 `support` 值动作映射）。
4. 全量测试绿；`npm run build` 通过；日志页可见 `novel_support_check` stage 与判定分布。
