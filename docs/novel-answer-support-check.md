# 演义域回答-片段支撑校验（长期机制）设计：单轮生成 + 结构保险丝

> 类型：技术方案（决策与理由 / 契约 / 风险 / 验证，不写流水账）
> 关联：bug-00028（凭先验作答 + 引用不支撑）、feat-A004（拒答红线）、feat-A006（引用结构化）、feat-A011（提示词瘦身）、feat-A013（缓存）
> 作者：Coco ／ 日期：2026-09-24 ／ 状态：定稿（Coco 定案，技术取舍见正文；成本口径以本版为准）

## 问题与目标

- 问题 A（语义）：演义域生成轮凭先验作答——注入片段不支撑结论仍答出史实，并挂不支撑引用（9eb73dad 马超五虎上将 / 官至骠骑 / 英年早逝等）。提示词约束在、模型不服从（bug-00028 主因）。
- 问题 B（机制）：词表型规则裁决不可维护——死亡 / 数值 / 表字信号是词表型判定，新问法就要加词表，最终堆成不可维护的规则墙（负责人定性）。
- 问题 C（成本与方向）：独立复核轮（第二次 LLM 调用）使每次回答的输入 token 与串行延迟翻倍，负责人否决作为长期主机制；提测期把非幻觉案例（92276ba8：白话「右眼」问、演义「左目」答的语体差异 + 用户前提与演义不符）误当 bug 修，方向错误。
- 目标：每次回答保持 1 次 LLM 调用（成本 / 延迟与现网生成轮一致）；语义裁决收回生成轮；规则层收缩为问法无关、可穷尽、可维护的结构不变量；不堆词表、不增 LLM 调用。

## 决策与理由（备选 → 为什么选它）

1. **撤销复核轮**（stage=novel_support_check，生成轮后第二次 LLM 调用，含 supportCheck.ts 与其编排接入）。
   - 备选：保留复核轮但精简输入 → 调用次数 / 串行延迟翻倍的本质不变，否决。
   - 备选：同轮自检（生成时要求先自评再作答）→ 与被裁对象同模型同上下文，正是「约束在、模型不服从」的失败面本身，不能作为唯一裁决手段；可作为 prompt 辅助，不承担裁决责任。
   - 代价：语义裁决与被裁对象同源，漏放概率高于复核轮；由结构门机械拦截 + 观测兜底（见风险）。
2. **语义裁决 = 生成轮通用语义指令**（只写语义，不写任何案例词 / 问法）：
   - 片段外信息不写不补（治知识注入，9eb73dad 类）；
   - 必须直接回答用户问题本身——答非所问（问 A 答 B、问结局答过程）视为不合格（治 2b12dd5f 类）；
   - 问题前提与演义不符（左右目、时间、人物关系、归属）→ 先按演义事实说明 / 校正再作答，不硬凑、不拒答（治前提冲突与语体差异，92276ba8 类）。
   - 硬规矩沿用：任何「新增语义规则 / 词表」的诉求 = 报警信号 → 架构评审，禁止靠规则兜语义。
3. **保险丝 = 结构门（零 LLM、问法无关、可穷尽）**，在既有两条基础上新增第三条：
   - 保留：引用指针必须指向本次注入的片段（validateQuotePointers）；答案断言人物 ⊆ 召回人物（verifyCitation）。
   - 新增：事实句必须与所标片段有可观测文本重叠——标点 / 空白 / 数字全角归一后，句内 n-gram 与片段重叠达到阈值才放行；引语沿用服务端渲染，叙述句按归一化比较。重叠不足 → 裁剪该句；答案无留存句 → 拒答「演义中未涉及」+ 清空引用（A004 红线）。
   - 说明：该门是文本结构不变量而非语义词表——不依赖问法与词汇枚举，随片段文本自适应，可穷尽、可测试。
   - 移除：死亡证据词表、数值同值判定、表字值判定（同原议）。
4. **拒答 / 裁剪口径**（与既有 A004 红线一致）：「演义中未涉及」只表「原文未涉及」，不表系统故障；裁剪后无留存句按拒答；拒答类不写缓存（cache.ts 既有规则）；缓存命中跳过生成（缓存内容即裁剪后答案）。
5. **fallback 归纳轮保持现状**：引用校验 / 格式不过时的兜底归纳（concludeFallback，非每次调用，不构成常驻成本）。
6. **日志契约（A007）**：删除 novel_support_check stage（不留新 stage，不新增字段）；观测点改为「结构门裁剪句数 / 裁剪后拒答数 / 拒答率趋势」，由服务端在既有日志上聚合。

## 风险 & 已知约束

- 单轮语义裁决与被裁对象同源：模型绕过指令时可能漏放（概率高于复核轮）。缓解：知识注入由「句-片段文本重叠」结构门确定性拦截；答非所问根子在检索侧（「投靠后」等无片段召回，如 2b12dd5f），回答层只做提示词约束 + 拒答，根治走检索侧课题（另立 bug 票，不属本票）。
- 文本重叠门误裁风险：模型流畅改写与原文差异大时可能误裁。口径 = 宁缺勿猜；阈值参数化、默认从严，用裁剪率观测调参，不靠堆规则。
- 前提冲突 / 语体差异类（92276ba8 等）非幻觉，不按 bug 修、不拒答：由生成轮按演义事实校正说明，验收不计缺陷。
- 不涉及：检索 / 注入预算 / 权重 / mcp-server 出参契约，均不动。

## 验证（可判定）

1. 三例回归 + 问法变体：知识注入类（9eb73dad 马超五虎 / 官至骠骑 / 英年早逝等）裁剪或拒答；答非所问类（2b12dd5f「投靠后」答前事）拒答「演义中未涉及」或按问题主体直接作答；前提冲突类（92276ba8 左目 / 右眼）给出演义事实校正说明，不拒答、不编造。
2. 正例不误伤：表字正例（元让在片段）、数值同值正例（55 ↔ 年五十五）、纯叙述放行（控制组）。
3. 结构门单测（含文本重叠阈值边界：低于阈裁剪 / 高于阈放行；指针非法；人物 ⊆；裁剪后拒答）；生成轮提示词措辞断言（三条通用指令在，无案例词）。
4. 全量测试绿；npm run build 通过；日志无 novel_support_check stage。
