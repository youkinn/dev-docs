# PR 描述乱码（`\b` 被当作退格符）根因与修复

> 类型：开发流程 / 工具使用（非业务文档）
> 适用：创建 / 编辑 PR 描述时文本含 `\b`（反斜杠 + 字母 b）序列，GitHub 正文出现 `\` + 退格符乱码
> 记录：Coco，2026-09-23
> 关联：PR #37（bug-00024 登记）；负责人反馈「刚刚 PR 有乱码，应该是 commit 消息」，核对后定位在 PR 描述正文

## 现象

PR #37 在 GitHub 上描述正文两处 `bugs/` 显示成 `\ugs/`，中间夹一个**退格符（U+0008）**——肉眼看不到 0x08，但拷贝出来是 `\` + 退格 + `ugs/`。

实测字节（`gh api .../pulls/37 --jq .body` 落到文件）：

```
... 2D 20 E6 96 B0 E5 BB BA 20 5C 08 75 67 73 2F ...   # 即 "新建 \" + U+0008 + "ugs/"
```

影响范围核验：

| 对象 | 字节核验 | 结论 |
|------|----------|------|
| PR #37 描述 | 2 处 `5C 08 75 67 73`（`\` + U+0008 + `ugs`） | **有乱码（本次问题）** |
| commit 消息（71d0ab3） | 合法 UTF-8，`登记同题异答缺陷…` 解码正确 | 无乱码 |
| `bugs/bug-00024-answer-quote-missing.md` | 合法 UTF-8 无 BOM | 无乱码 |
| `bugs/INDEX.md` 新增行 | 合法 UTF-8 | 无乱码 |
| PR #37 标题 | `docs: 登记 bug-00024（…）` | 无乱码 |
| 其余 PR（最近 100 个） | 全量扫描无 U+0008 | 无同病 |

## 根因链条（分层）

1. **源头（负责人消息原文即如此）**：需求文本里路径写成 `\ugs/bug-00024-…md`、`\ugs/INDEX.md` —— `bugs` 首字母 `b` 丢失、前面多出一个反斜杠（输入 / 复制粘贴环节已变形，进到 PR 前就是错的）。
2. **传播**：创建 PR 时把这段文本原样搬进描述，正文形成 `\b` + `ugs/`（反斜杠后紧跟字母 b）。
3. **变质（直接根因）**：在 JSON 字符串转义里 `\b` 是合法转义序列，含义是**退格符（0x08）**。创建 PR 的 body 未经转义就把含 `\b` 的文本拼进 JSON（或经某层转义处理），GitHub API 按 JSON 解析把 `\b` 解释成 U+0008 → 服务器最终存下 `\` + U+0008 + `ugs/`。若反斜杠正确转义成 `\\`，`\b` 不会被吃掉。
4. **结论**：不是仓库文件 / 提交消息编码问题，是「文本含 `\b` 序列 + 创建 PR 时 JSON 转义缺失」组合出的单点事故。

## 修复

- 用修正文本重建 PR 描述，走文件输入避免命令行编码与转义二次踩坑：

```powershell
gh pr edit 37 --body-file <UTF-8 无 BOM 的 body 文件>
```

- 修正内容：`\ugs/bug-00024-answer-quote-missing.md` → `` `bugs/bug-00024-answer-quote-missing.md` ``；`\ugs/INDEX.md` → `` `bugs/INDEX.md` ``（路径改用反引号包裹，正文其余不动）。

## 验证

- `gh api repos/youkinn/dev-docs/pulls/37 --jq .body` 字节检查：无 U+0008，两处路径为 `bugs/...`。
- 全量扫描最近 100 个 PR 描述，仅 #37 曾含 U+0008，其余无同病（本次只修 #37，其他不动）。

## 预防（约定）

1. **反斜杠警惕**：文本里出现 `\b` / `\n` / `\t` / `\u` 等反斜杠序列时，先想它会被哪层转义处理解析；路径一律用反引号包裹（如 `` `bugs/xxx.md` ``），且不要以 `\` 开头。
2. **PR 描述走文件**：创建 / 编辑 PR 描述一律 `--body-file` 传 UTF-8 无 BOM 文件，禁止在命令行参数里直接拼中文 + 反斜杠（Windows 下还叠加 GBK/CP936 命令行编码问题）；手拼 JSON body 必须先转义反斜杠，或用 `gh` / `jq --arg` 让工具自动转义。
3. **交付前自查**：`gh pr view <号> --json body --jq .body` 肉眼扫一遍，见到 `\` + 字母组合多留一份心。
