# feat-A006: 答案展示结构化（结论 + 引用出处卡片）

> 特性号：feat-A006
> 状态：待定稿（负责人评审中，2026-09-20）
> 作者：Coco
> 涉及项目：mcp-orchestrator（总台）, mcp-web（前厅）
> 日期：2026-09-20
> 关联：feat-A004（服务端渲染引用/出处）、bug-00005（引用与结论不相关，**不在本条范围**）

## 背景

feat-A004 为「前端零改动」，把引文 + 出处由服务端渲染成一段纯文本拼进 `data.answer`，前端按纯文本展示（A004 接口文档明确「若需拆分结论 / 引用 / 出处，须另行提出」）。实测观感：多个出处摞在一段里，阅读不便；多片段连排还容易让用户误读为连续叙事。

本次按负责人拍板的样式定稿（2026-09-20）：响应结构化，`answer` 只放结论，引用片段 + 出处下沉到 `citations`，前端以「结论段 + 参考资料卡片区」两段式展示。

## 目标

- [ ] `POST /api/chat` 响应 `data` 扩展 `citations`，`answer` 不再内联出处
- [ ] 前端两段式展示：结论段 + 参考资料卡片区；连续同回目合并分组；跨回目视觉断裂
- [ ] 仅影响 `sango-novel`（含自动路由落入该域）；天气 / 风云三国展示逻辑不变，互不影响
- [ ] 兜底路径（原文片段 + 出处 + 结论句）同样结构化
- [ ] 附带小改：主页「已接入能力」更新为实际能力列表；文案「连接工具，让能力逐步长出来。」收敛到一行

## 非目标

- 不修 bug-00005（引用与结论不相关）——相关性是 bug 单问题，本条只解决展示排版
- 不展示段号、不引入 `segFrom` / `segTo`（沿用 A004 约定）
- 不改 mcp-server 工具契约（`sango_novel_search` 出参不动）
- 不做流式输出（BL-014，另行立项）
- 不做片段折叠 / 展开交互（v1 卡片直出片段全文，≤400 字/卡）

## 接口契约（老陈出接口文档时直接引用）

### 统一形状（全域抹平，2026-09-20 负责人确认）

- `POST /api/chat` 与 `POST /api/sango/random` 响应 `data` **统一**为单一形状 `{ answer, citations }`，不做 domain 分支
- 无引用时 `citations` 恒为 `[]`，**不省略、不缺失**；weather / fengyunsanguo（含随机一题）永远为空数组，行为与现状零变化
- 前端单一渲染路径：`answer` 段 + `citations.length > 0` 时渲染参考资料卡片区；角标 `¹²³` 是服务端拼进 `answer` 的普通字符，前端零解析
- 兼容：字段只增不减，旧前端忽略 `citations` 照常工作；A006 总台与前端同发，无中间态
- 以后新增域默认 `citations: []`，契约不再变更

`POST /api/chat`，`domain=sango-novel`（或自动路由落入 sango-novel）响应示例：

```json
{
  "code": 200,
  "data": {
    "answer": "关羽拒绝了孙权的联姻，回以「吾虎女安肯嫁犬子乎！不看汝弟之面，立斩汝首！再休多言！」¹。",
    "citations": [
      {
        "text": "瑾曰：“特来求结两家之好……请君侯思之。”云长勃然大怒曰：“吾虎女安肯嫁犬子乎！不看汝弟之面，立斩汝首！再休多言！”",
        "chapter": 73,
        "title": "玄德进位汉中王　云长攻拔襄阳郡"
      }
    ]
  },
  "message": ""
}
```

### 字段口径

| 字段 | 类型 | 说明 |
|------|------|------|
| `answer` | string | 结论正文。服务端把模型输出 `[Qn]` 指针替换为渲染引语 `「引文」`，引语后跟**全局角标号**（`¹²³`，上标，按出现顺序从 1 起）；**不再内联出处** |
| `citations` | array | 按引用出现顺序的扁平数组；每条含 `text` / `chapter` / `title`；无引用时为 `[]` |
| `citations[].text` | string | 命中片段原文（工具出参 `text`，即注入视图「片段N」），可含引语；无回目 / 段号 / 类型 / 分数 |
| `citations[].chapter` | number | 片段所在回（回号） |
| `citations[].title` | string | 片段所在回的回目 |

- 角标号与 `citations` 下标**一一对应**（第 1 条引语下标 0 → 角标 ¹）
- 多个引语落在同一片段 → 合并为一条 citation（片段粒度），角标数量 = 片段数量
- 兜底路径：`answer` 放结论句，`citations` 放一条兜底片段，结构相同
- weather / fengyunsanguo（含 `/api/sango/random`）：`citations` 恒为 `[]`，行为与现状零变化
- 兼容性：`answer` 自洽可独立成读，旧前端忽略 `citations` 不受影响（仅无卡片区）

## 展示规则（前端，小叶实现）

1. 两段式：`answer` 结论段自成一区；`citations` 渲染为「参考资料」卡片区，一卡一条
2. **连续同回目**（`chapter` + `title` 相同）合并为一个分组：出处头只出现一次，组内条目保留各自全局角标
3. **跨回目**另起分组 / 独立卡片，用出处头 + 分隔线强制断裂，防止用户误读为连续叙事
4. **同回目但不连续**（中间隔着其他回）不合并，保持原顺序
5. 卡片顺序 = `citations` 顺序，**不按回目重排**（角标要对得上）
6. 段号不出现在任何展示位；角标随引语渲染，前端零解析

前端观感（定稿样式，供小叶参考）：

```text
关羽对孙权的联姻予以回绝，态度激烈¹，并明言「吾虎女安肯嫁犬子乎！……」²。

参考资料
────────────
第73回 玄德进位汉中王　云长攻拔襄阳郡
  ¹ …瑾曰：“特来求结两家之好……请君侯思之。”…
  ² …云长勃然大怒曰：“吾虎女安肯嫁犬子乎！……”…
────────────
第42回 张翼德大闹长坂桥　刘豫州败走汉津口
  ³ …我在此等候多时了！…
────────────
```

## 验收标准

- [ ] 跨回多引用：`answer` 结论 + N 卡片，角标一一对应
- [ ] 同回多条引用：合并一个出处头，组内条目角标连续
- [ ] 兜底路径：`citations` 恰好一条
- [ ] 无引用：`citations` 为 `[]`，前端无卡片区
- [ ] weather / fengyunsanguo（含 `/api/sango/random`）`citations` 恒为 `[]`，前端展示与现状一致
- [ ] 任何展示位不出现段号
