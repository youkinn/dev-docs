## 背景

- 排查「LLM 答歪」需要把「喂给模型的料」与「模型产出」解耦：以 traceId 带入现场片段，手工增删 / 排序，手动触发生成，验证答案段是否预期（负责人 2026-09-26 定口径）。
- traceId 即用例：每次线上请求的注入片段天然可复现，无需另建用例库。

## 目标

- [ ] 草稿台（日志页按钮 → 弹框入口）：输入 traceId → 拉取该请求 chunk 列表（左栏，只读源）；构造本次发送清单（左拖右添加 / 右内拖拽排序 / 右侧手增与移除）；发送弹框确认（query / 片段摘要 / 本次参数一次过目）后走生产同一 /api/chat（带来源标记），手动触发生成，程序不自动调
- [ ] 结果展示：生成后一眼确认「缺 / 错 / 对」——发送清单与生成结果（注入 / 引用）逐条对照，一致 / 缺失 / 多余三态高亮（CLI 符号表、页面颜色）
- [ ] 本次参数（请求级覆盖）：温度、topK 注入条数 / 保底数、注入总预算——打开 traceId 默认带出该请求线上实际配置为默认值；query 可编辑（微调措辞）
- [ ] 操作便利性：负责人全程页面独立完成（不只是能用，要好用）
- [ ] 调用记录与来源筛选：草稿台与生产同源（同 /api/chat / 同一日志体系），数据靠「来源」区分——日志页加来源筛选（默认仅生产，可切换草稿台）；草稿台弹框内列表只显示草稿台记录；详情复用日志页分析视图，可一键载入复现
- [ ] 数据隔离：默认日志视图不出现草稿台数据；显式切「来源=草稿台」才可见

## 验收标准

每个标准可验证（对 / 错，无灰色地带）：

1. [ ] CLI 可用：指定 traceId 拉取原 chunks → 增删 / 排序 / 插片段成新列表 → 手动触发生成 → 输出注入清单 + 答案 + 引用；本次实际参数（温度 / topK / 预算，默认带出线上值）可读
2. [ ] 页面版可用：与 CLI 同一后端接口；左栏只读源 + 拖拽 / 手增 / 排序 / 移除 + 发送按钮 + 差异展示；真浏览器实测（AGENTS.md 第 11 条）
3. [ ] 差异可读：同一 traceId 复跑，发送清单与结果对照，一致 / 缺失 / 多余三态可辨
4. [ ] 本次参数请求级：温度 / topK / 预算覆盖仅本次生效，日志 / 诊断可读证实际用值；query 编辑生效；git 检查确认线上配置零改动
5. [ ] 便利性：负责人独立走完「复制 traceId → 拉取 → 拖入 / 手增 → 排序 → 发送 → 读结果」，全程页面交互、无需拼接 chunkId；构造到发送 ≤5 步
6. [ ] 记录与筛选：草稿台发送后，日志「来源=草稿台」筛选可见该记录且字段齐全（时间 / traceId / query / 参数 / 片段数 / 结果）；点击记录可载入（清单 + 本次参数）继续编辑
7. [ ] 数据隔离：默认日志页 / 链路查询不含草稿台数据；草稿台弹框列表只含草稿台记录；真浏览器实测

## 接口影响

- 草稿台发送 = 复用生产 /api/chat（带来源标记 = 草稿台），数据天然进现有日志体系，无需独立记录存储；老陈接口文档先行，小叶依赖
- mcp-orchestrator 日志查询接口支持来源筛选；新增草稿台辅助接口（traceId 拉取该请求 chunks + 线上实际参数）
- mcp-web：日志页新增「草稿台」按钮（弹框入口）+ 来源筛选
- 生产默认路径行为不变

## 技术要点

- traceId 拉取：反查该请求链路候选 / 注入 chunks（tool_retrieval_logs 与现有日志链路），左栏展示回目 / 段位 / 原文预览
- 手动生成：以新清单走与生产相同的生成 / 校验管线（引用校验 / 结构保险丝），结论可外推；温度为请求级参数覆盖，不落生产配置
- 本次参数默认带出：接口返回该 traceId 请求的线上实际配置（温度 / topK / 预算）为默认值，覆盖仅本次生效；模型切换不设计（当前单模型，后续考虑）
- LLM 调用口径（红线 14 报备登记，2026-09-26）：草稿台全手动触发，单次点击 = 1 次生成调用，无程序自动调用、无批量、无重试设计；预算 = 负责人手动点击次数，天然有界
- 交互：左右双栏，右栏为最终发送清单；发送走弹框（query 可改、片段数 / 总字数、本次参数一次过目），确认后生成
- 数据同源：草稿台与生产同走 /api/chat，仅来源标记不同；llm_call_logs / tool_retrieval_logs 等天然记录，分析直接复用日志页视图（图表 / 时间线 / 详情）
- 隔离 = 来源筛选：日志页默认仅生产，显式切「来源=草稿台」才见草稿台数据；草稿台弹框列表同样按来源过滤；点击记录载入（片段清单 + 本次参数）继续编辑
