## 背景

- 目前只做了人名归一化；地名 / 战役名 / 典故变体（五关斩六将 vs 过五关斩六将，差一字漏召）/ 器物 / 身体部位（左右目 vs 左右眼）/ 官职 / 数字称谓均无归一化；先统计差异清单再统一（负责人 T1）。
- 缓存侧 `sango_query_embed` 吃原始 query：若只在检索侧改写，缓存与检索口径分裂，换说法查询与规范形各占一条缓存（D4）。
- 负责人拍板：口径统一单开特性号（D11）。

## 目标

- [ ] 统计脚本（零 LLM）：基于标准集与线上 query，产出「除人名外需统一口径」的差异清单（类型 / 示例 / 预期规范形）
- [ ] 人物别名表增量：资料人物节并入新表（保留 PID；冲突组 bug-00031 不进表）
- [ ] 表收敛为一份（含人名 alias→ID / 换说法 / 类型维度）：alias.json 并入新表，检索侧与缓存侧共用同表同实现（单一数据源、单一口径）
- [ ] 规范形口径统一：取消 df 选名，规范形由表直接指定（行首列 = 规范形），人名与换说法同一口径
- [ ] 检索侧：query 在 embed 之前完成改写（换说法 → 规范形 / 别名扩展），双侧归一化（query 与片段索引）
- [ ] 缓存侧：embed 前对 query 做同一归一化，换说法与规范形共享同一缓存条目

## 非目标（明确不做的事）

- 不做大规模实体库建设：只按统计清单推进，白名单式表，避免误匹配
- 同字不同人冲突（bug-00031）本期不修：冲突组不进表，后续单独处理
- 不改注入策略与检索权重（分别为 A020 / A014 范畴）
- 不引入 LLM 参与改写（规则表优先；若统计显示需语义改写，另议）

## 验收标准

每个标准可验证（对 / 错，无灰色地带）：

1. [ ] 口径差异清单报告落档：≥3 个类型有实际案例（标准集或线上 query 实测为证），含「五关斩六将 / 过五关斩六将」与「左右目 / 左右眼」两例
2. [ ] 别名 / 换说法表文件落地，检索侧与缓存侧读取同一份表
3. [ ] query 改写发生在 embed 之前：同义换说法问题改写后与规范形检索结果一致（top10 证据段集合相同）
4. [ ] 缓存键归一化生效：换说法 query 与规范形 query 命中同一缓存条目（缓存日志可读证：一次 LLM 调用而非两次）
5. [ ] 漏召修复回测：`过五关斩六将` 与 `五关斩六将` 均能在 top10 召回同一典故证据段
6. [ ] 人名规范形口径切换回测：`关羽` / `云长` query 归一化到同一规范形，标准集 top≤10 不回退 + 华雄 / 刘备定点不倒车（recall-bench 同基线复跑）

## 技术要点

- 单表结构：行 = 类型（人名 / 地名 / 战役 / 器物 / 官职 / 时间 / 典故 / 身体 / 数字称谓…）+ ID（人名沿用 PID）+ 规范形 + 别名列表；alias.json 并入本表（人名行保留 PID，供人物标签 / 死亡类逻辑复用），换说法与别名同文件维护、加载进内存
- 现有 alias.json 核查（2026-09-25）：398 别名 / 148 PID；双侧统一归一化 + 最长匹配结构沿用；规范名原按语料 chunk 级 df 选取，本期取消该逻辑、改由表直接指定（df 口径选不出语料外说法的规范形，无法覆盖换说法表）
- 缓存侧与检索侧共享同一 normalize 实现（含人名与换说法），编排侧不另写，防 D4 口径分裂；缓存键随规范形口径变化，切换时清一次缓存
- recall-bench 同步改用表指定规范形，维持「检索实现与评测口径一致」既有契约
- 表设计约束（沿用核查结论）：泛称（皇帝 / 天子 / 丞相等跨主条目词）禁入改写键，仅收演义唯一指称；同字不同人冲突词不进表（先立冲突清单，再定单值 alias→PID 结构是否扩为多值）
- 白名单素材底稿：docs/sango-entity-normalization.md（12 类 + 数字称谓交叉子类）
- 数字称谓 = 含数字的典故固定称谓（三英战吕布 / 五虎上将 / 六出祁山 / 九伐中原 / 过五关斩六将等），统计清单单列子类
- 表键约束：单字词（目 / 口 / 头 / 死 / 亡等）不作 query 改写键，仅作片段侧同义素材；年号类用带年份短语键，防同词歧义（建兴 = 蜀汉 / 吴）
- 嵌入前改写是硬约束：否则缓存与检索口径分裂（D4）
- 白名单式：只映射已确认条目，未知词不动，控制误匹配

## 风险 & 开放问题

- 换说法命中率未知：先统计（可佐证 A015 池覆盖探针），覆盖率低则扩大表或转语义改写评估
- 归一化误匹配（过归一化）：以白名单 + 漏召回测样例兜底
- 同字不同人 4 组（子远 / 公明 / 子明 / 子孝）：已登记 bug-00031（待修复），本期冲突词不进表，不阻塞主线
