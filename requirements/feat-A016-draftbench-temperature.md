## 背景

- 排查「LLM 答歪」缺乏不依赖召回质量的实验手段：无法固定问题与片段，观察注入顺序 / 温度等变量对输出的影响（负责人：固定问题 + 片段让 LLM 生成，反推召回还缺什么，T0）。
- 叙事序（D6）：多段注入时模型看到的顺序可能与叙事顺序不一致；实现口径已定（先完成 top5 保底 + 6–10 预算选择，再对最终清单按 (chapter, segFrom) 排序后编号），需实验验证再决定是否生产化。
- 温度 0.7（全局）对演义域是否偏高未验证，候选 0.1–0.3（负责人建议 T0 实验）。

## 目标

- [ ] 草稿台：固定问题 + 手工指定片段 → 走同一生成 / 校验管线，输出答案与引用；CLI 先行，页面版随本需求交付（负责人参与测试）
- [ ] 失败模式回归集：在草稿台沉淀可复现用例集（含 bug-00024 / bug-00025 现象各 ≥1），供后续迭代（A020 等）回归
- [ ] 叙事序开关：实现「仅重排呈现」档（选择逻辑不动、只改呈现顺序）与「重排参与选择」激进档，草稿台可对照实验；默认关，结论后定是否生产化
- [ ] 温度按域：演义域温度可配置（候选 0.1–0.3），草稿台对比实验出结论

## 非目标（明确不做的事）

- 不改生产注入选择逻辑（叙事序默认关；生产化决策由 A020 收口）
- 不做全局温度调优（只按域配置与对比）
- 不做重排模型（A018）与术语归一化（A017）

## 验收标准

每个标准可验证（对 / 错，无灰色地带）：

1. [ ] CLI 可用：输入问题 + ≥1 个片段（chunkId 或原文），走生产同一管线产出答案 / 引用 / 注入清单；输出可读叙事序开关档位与温度参数
2. [ ] 页面版可用：同一入口，负责人可操作（UI 类改动按 AGENTS.md 第 11 条真浏览器实测）
3. [ ] 叙事序两档对照：同一问题 + 同一片段集，可复现「仅重排呈现」与「重排参与选择」两份结果，差异可读
4. [ ] 温度按域生效：演义域按配置温度请求 LLM（日志 / 诊断可读证），0.7 与候选值（0.1–0.3）对比报告落档
5. [ ] 回归集 ≥5 例（含 bug-00024 / bug-00025 现象各 ≥1），草稿台一键重跑
6. [ ] bug-00024 / 00025 在回归集上定性，能顺带修则修（不占独立排期）

## 接口影响

- mcp-orchestrator 新增草稿台接口（问题 + 片段清单 + 参数覆盖 → 生成结果）；老陈接口文档先行，小叶依赖
- mcp-web 新增实验入口与结果展示
- 叙事序 / 温度参数仅在草稿台与开关路径生效，生产默认路径行为不变

## 技术要点

- 叙事序实现位点：`buildInjectionView` 内「保证 / 预算判定之后、编号之前」；开关默认关
- 片段注入走与生产相同的校验管线（引用校验 / 结构保险丝），保证实验结论可外推
- 温度按域：现有温度读取点加域覆盖（演义 0.1–0.3 候选），日志可读证

## 风险 & 开放问题

- 叙事序「仅重排呈现」对 top5 保底无影响（已确认），但 6–10 兜底位参与排序的极值场景需在回归集覆盖
- 温度结论依赖人工判读（0.7 vs 0.1–0.3 答案质量），由负责人抽样判读、程序不批量跑
