## 背景

- 现评测集 cls2400 由 AI 随机生成：重复问题与垃圾问题多，**不作标准**（负责人 2026-09-24）：判据数字建立在不可信问题上，无法支撑「召回变好还是变坏」的结论。
- 判定原则见 bug-00008（2026-09-19 登记，状态待修复）：表述差异不算错、参考答案降级为实体定位线索、禁止字面逐字对标（字面口径仅保留给引语型答案作下界）。**判对 / 检索侧判据按注入策略定稿（2026-09-20）**：判对 = 答案段进 top5 且注入可见（前 5 整段保底必注入）；6–10 为过渡兜底、救回案例单独统计、不算正式判对；`证据段进 top3` 是注入上限 = 3 时代的旧阈值，随 2026-09-20 注入定稿退出。分类器 `recall-classify-900.mjs` 仍为旧字面 2-gram 口径；A1（字面可拼齐＝真漏召）/ A2（字面无落点＝口径待判）拆分与实体口径并行输出、禁止互相替代的要求尚未落地。
- 需要一个可复现、可人工审定的基线，才能承接后续 A017 归一化 / A018 重排等改进的回归验证。

## 目标

- [ ] 重建标准集：人物 / 地名 / 战役 / 典故 / 器物 / 身体部位 / 官职 / 数字称谓 / 事件关系 / 死亡 / 拒答，共 11 类，每类 5–10 问（合计 55–110 问），人工起草、负责人抽样审定
- [ ] 分类器按统一口径落地（2026-09-20 注入定稿）：判对 = 答案段进 top5 且注入可见、表述差异算对、参考答案仅实体定位线索；6–10 兜底救回单独统计、不算正式判对；A1（字面可拼齐＝真·检索漏召）/ A2（字面全库无落点＝口径待判）拆分 + 实体口径并行输出、禁止互相替代，读数标注口径
- [ ] bug-00007 收口：标准集与 cls2400 的去重 / 错标 / 超纲整改结论落档
- [ ] 池覆盖探针（T1-c0，零 LLM）：量出每问证据段进入检索前 50 路候选池的覆盖率，作为 A018 重排选型的输入

## 非目标（明确不做的事）

- 不做重排 / 归一化 / query 改写等任何检索改进（分别由 A018 / A017 承接）
- 不引入大批量 LLM 评测：批量 LLM 测评由负责人抽样执行，程序不批量跑（token 控制）

## 验收标准

每个标准可验证（对 / 错，无灰色地带）：

1. [ ] 标准集落地（`dev-docs/test/standard-set/`，结构化格式），11 类齐全、每类 5–10 问；每问含：问题 / 证据段 chunkId（或原文定位）/ 参考答案（仅实体定位线索）
2. [ ] 负责人审定通过：每类人工抽查 ≥3 问，判定口径（表述差异算对、参考答案不作逐字对标）执行一致
3. [ ] 分类器输出 A1（字面可拼齐＝真·检索漏召）/ A2（字面全库无落点＝口径待判）+ 实体口径并行，实现与 bug-00008 修复方向一致（评审对照可验证，非自证）；判对判据按 2026-09-20 注入定稿（答案段进 top5 且注入可见），6–10 兜底救回单列；读数标注口径（字面 / 实体）不混用
4. [ ] 标准集跑分基线报告：bestRank top≤5（KPI）/ top≤3 / top≤10（标准集上，不含 cls2400）
5. [ ] 池覆盖探针（零 LLM）输出：每问证据段是否入 50 路候选池 + 覆盖率，报告落档
6. [ ] bug-00007 / bug-00008 状态按收口结论更新到 `bugs/INDEX.md`

## 技术要点

- 标准集结构：分层（类 → 问题 → 证据段 + 参考答案定位）；证据段以 chunkId 定位，供探针判「入池 / top3 / top10」
- 分类器修复点：`recall-classify-900.mjs` 的字面 2-gram 匹配改为语义判定（表述差异算对）；A1 / A2 定义以 `docs/sango-recall-quality.md` 为准，不在本需求重定义
- 池覆盖探针：零 LLM，数据源沿用 `dev-docs/test/recall-injection-probe.mjs` 先例直连 `SangoIndex.search()` 拿全量候选（向量路 top50 + 词法 + 标签融合池）；日志 `diagnostics.candidates[]` 仅供辅助——受 `MAX_DIAGNOSTIC_CANDIDATES=20`（`sango-index.ts:84`）截断，不能代表 50 路池；覆盖率 = 证据段入 50 路池问题数 / 总问题数
- 全部脚本零 LLM，遵守输出护栏（AGENTS.md Token 控制第 8 条）

## 风险 & 开放问题

- 标准集问题主观性：以「负责人审定」为唯一通过标准；每类 5–10 问为下限，不追求大而全
- A1 / A2 定义若与现状实现口径有出入：以 `docs/sango-recall-quality.md`（bug-00008 定稿）为准，差异在评审时指出
- cls2400 处置：整改后保留为辅助集，不作为基线（结论归 bug-00007）
