# feat-A004 三国演义解读（只解读不评论）· 需求定稿

> 技术方案：`docs/sango-classics-rag-design.md`｜调研 / 决策 / 探针：`docs/sango-classics-rag-research.md`

## 场景与目标

- 三国迷问演义情节，只给「原文怎么说」；独立标签，只讨论演义。
- 拒答是验收核心：原文没有的必须答「演义中未涉及」，禁止先验补全。

## 明确非目标

不做演义 / 正史对比、不评价对错、不做文学批评；不做 query 改写、rerank、专用向量数据库；二期《三国志》仅预留 `source` 维度，本期不做。

## 关键技术口径（摘要）

- 检索 = MCP 工具 `sango_novel_search`，单入参 `source` 定会话上下文（D1）；BM25 + 向量 hybrid（本地 embedding 离线产物，D2/D5）。
- 生成 = 快路径（domain=sango-novel 服务端预先检索 + 注入片段 + 单次 LLM 生成，确定性优先）+ prompt 限定（6 条规则，含引语指针格式）+ 引用硬校验（断言人物集合 ⊆ 召回人物集合，本地别名表 ID 扫描 + **指针校验**，0 次 LLM）+ **引用与出处由服务端按 `quotes[]` / `chapter` / `title` 字段渲染**（模型不生成引语原文与出处）+ 兜底（原文直出 + 结论句，同样字段渲染）。探针 A 已实测：H2 通过（鲁棒性口径）。
  - 2026-09-18 变更（feat-A004 chunk 规范落地）：出参由「拼接文本块 + 【出处】头」改为结构化条目数组；校验由「固定格式校验」改为「指针校验 + 长引语安全网」。口径见 `docs/sango-corpus-spec.md` §5/§6 与 `mcp-orchestrator/api/feat-A004-sango-classics-rag.md`。

## 验收口径（负责人执行）

- 鲁棒性：即便有干扰（记忆冲突、线索看似矛盾）仍给出与知识库匹配的答案；拒答不得退化为编造。
- 响应时间目标：`domain=sango-novel` 快路径下目标 1~2s 返回（LLM 调用 1 次）；当前实测 7~17s，受火山方舟无缓存 + 注入片段过长影响，待「火山缓存开通（用户负责）+ 注入上下文收窄（小胡工作单）」落地后验收。
- 引用与出处：检索命中回答的**展示形态不变**——「结论 + 「引用的原文」（出处：第X回 回目）」，出处只到回目、不展示段号；但**引语原文与出处由服务端从语料字段渲染**，模型只输出结论 + 引语指针（如 `[Q2]`）。由服务端本地引用校验 + **指针校验**（+ 超 30 字长引语安全网）强制，不靠模型自觉。
- 探针 A（H2）已通过；探针 B（H1 召回质量）**已固化**至 `mcp-orchestrator/scripts/probe/`（`chunk-sweep.mjs` 切分决策证据 + `recall-bench.mjs` 检索召回评测），可随时复跑。
