## 背景

- 叙事序（D6）：多段注入顺序与叙事顺序不一致可能影响 LLM 输出；实现口径已定（仅重排呈现：选择逻辑不动、选定后按 (chapter, segFrom) 排序编号），在 A017 草稿台实验，本需求收口生产化决策。
- 预算 2000 字（`INJECT_TOTAL_BUDGET`）：段被预算截掉目前无统计，无法量化「败在预算」的占比；倾向提召回质量、预算作备选，先量化再定（D7）。

## 目标

- [ ] 注入截断统计：被预算丢弃的片段数 / 字符数进入 recallDiagnostics，页面可读
- [ ] 预算评估：基于截断统计 + 标准集跑分，结论「提预算 / 不提、提多少」
- [ ] 叙事序生产化决策：依据 A017 草稿台两档对照结论，定「生产化 / 调整 / 关闭」

## 非目标（明确不做的事）

- 不改注入选择逻辑（生产化仅限排序呈现口径，D6 已定）
- 不做重排 / 归一化（A018 / A016）
- 不调整温度（A017 已评估）

## 验收标准

每个标准可验证（对 / 错，无灰色地带）：

1. [ ] recallDiagnostics 新增截断统计字段：预算丢弃片段数 / 丢弃字符数，线上与日志页可见
2. [ ] 统计报告落档：标准集 + 线上分布下，被预算丢弃的片段占比（量化结论）
3. [ ] 预算结论落档：提 / 不提及理由；若提，含新预算值与影响评估
 4. [ ] 叙事序决策落档：生产化 / 调整 / 关闭，含 A017 两档对照证据引用
5. [ ] 若生产化：开关默认值与灰度口径明确，A017 回归集不倒退

## 技术要点

- 截断统计实现点：注入预算判定处记录被丢弃片段（片段 id / 字符数）
- 叙事序生产化仅改呈现顺序：选定后排序再编号，注入内容逐字节一致
- 回归依赖 A017 失败模式回归集
