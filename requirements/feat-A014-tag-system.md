## 背景

- 标签体系 2026-09-19 由 LLM 提取器（`tags-prompt.md`）一次性批量生成，未经讨论与评审，无质量基线；标签设置是否合理、实现是否规范、是否引入噪声均存疑。
- 标签本意（负责人）：给同类 chunk 统一打标并加权，让它们在召回中「脱颖而出」——chunk 颗粒细导致召回碎片化，需要让同一事件 / 典故的整组 chunk 一起浮现，避免 LLM 断章取义。
- 线上第三路召回（TAG 0.1）实测对「宽泛匹配面」无增益（`sango-recall-quality.md` §13/§14：几百 chunk 同吃 +0.1 为整体平移），但该结论的噪声源集中在下述数据面：战役 / 政治事件等类型前缀随 bigram 成片命中（之战 610 / 政治 586 / 之死 268 / 登场 98）。
- 六类事件中 战役 / 政治事件 / 谋略计策 / 结盟外交 判定主观、LLM 生成不可信；人物之生 / 人物之死 / 单挑 客观可验证；典故（story.json）有通行名且质量实测较好（115 名、无死键、命名一致）。
- 负责人 2026-09-24 拍板：删除四类主观标签；**保留**第三路召回与 0.1 加权（0.1 是标签实现「脱颖而出」的意义所在，删除则标签失去作用）；治理匹配面噪声；典故分组定向与别名桥另立特性。

## 目标

- [√] 删除 event.json 中 战役 / 政治事件 / 谋略计策 / 结盟外交 四类标签（含 2 条 stray「典故事件」），保留 人物之生 / 人物之死；story.json、duel.json 完整保留
- [√] 保留第三路召回 + 0.6/0.3/0.1 加权与死亡意图置顶；索引层「标签剥壳」治理噪声（tagPostings 只入库剥离后文本，`之死 / 登场 / 人物 / 物之 / 之生` 等类型 bigram 清零）
- [√] 保留数据静态校验 + 校准（死键清零、许攸之死补标、重复登场修正、口径统一），人工抽检通过
- [√] 产出方向文档 `docs/sango-tag-system.md`（使用边界契约）并随本需求定稿

## 非目标（明确不做的事）

- 不做「典故 / 事件名定向置顶」与「组内目标段优先」机制（另立特性，方向文档 §3 记录路线）
- 不做别名表扩展（地名 / 典故名 / 战役名→规范名，即「白话问法→典故名」桥，另立特性）
- 不动注入策略（2026-09-20 已定稿：前 5 段保底 + 第 6-10 段预算竞争 + 2000 字总额、段内不裁剪；`INJECT_FRAGMENT_LIMIT=10` / `INJECT_HEAD_GUARANTEE=5` / `INJECT_TOTAL_BUDGET=2000`）
- 不动向量 / 词法权重配比（0.6 / 0.3 / 0.1 维持现状）

## 技术要点

- tags/*.json 为 chunkId → 标签文本（多标签 `|` 分隔），检索侧字符级 bigram 倒排（`sango-index.ts loadTags`）
- 删除实现：event.json 逐条目剥离四类标签（同 chunk 多标签只留 生 / 死），目标保留 471 条（生 135 + 死 336）
- **索引剥壳（索引层）**：`loadTags` 建 tagPostings 前对入库文本剥离类型信息（生 / 死 → 纯人物名；duel → `A-B`；story 原文即终型）；**数据文件与解析逻辑不动**，原始标签文本保留供 deathByPerson 解析与 hitLabels 回读。死亡 / 登场语义由结构（deathByPerson）承载。实测预期：华雄族命中面不变（2→2）、「华雄之死」270→5 且死亡段 `0005:c0015` 仍在
- 校验脚本：`sango/scripts/`（静态规则，零 LLM）

## 风险 & 开放问题

- 剥壳范围口径：前缀 + 后缀全剥（索引层）。「仅去前缀」对 `之死`（死标签 336 条均带此后缀）/ `登场`（生标签 135 条均带此后缀）无效（大头在后缀）；全剥后命中能力不降（华雄族 2→2、之死 270→5 死亡段仍在）；定稿确认
- 0.1 提升受「分数差距 ≤ 0.1」限制：gap 更大的案例（如华雄 #8）靠死亡意图置顶兜底，两者并存
- story「既生瑜，何生亮」含标点：通行典故名本身含逗号，豁免「无标点」规则
- 别名桥缺口（白话问法 → 典故名，如「刘备三请诸葛亮」→ 三顾茅庐）：已知，另立特性
- 回归判定基准：匹配面变化（剥壳）后标签路候选集缩小，排名判定以「证据段 top3 / top10 不劣化」为准
