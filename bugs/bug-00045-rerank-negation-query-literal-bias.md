# bug-00045 启用 cross-encoder 重排后拒答 / 否定型问句倒车（打分器词面偏好）

## 现象（A018 提测反馈测试项 3 跟踪）

启用态 = `mcp-server/sango/.env` 设 `SANGO_RERANKER=on` + A030 锁定档位（窗口 20 / 截断 128 / batch 16 / intra 8）。

定点复评（`scripts/verify-rerank.mjs`，离线真实权重、不调 LLM API）证据段 top10 名次：

| 定点 | 无重排 → 有重排 | 不倒车 |
|------|-----------------|--------|
| 华雄 典故#1（温酒斩华雄） | 3 → 4 | 否 |
| 华雄 拒答#5（华雄是孙坚杀的吗） | 6 → 0（跌出 top10） | 否 |
| 刘备 问法归一#4（驾崩多少岁） | 2 → 1 | 是 |
| 刘备 事件关系#10（白帝城托孤） | 1 → 1 | 是 |

- 池覆盖探针：4/4 证据段入 50 路候选池（拒答#5 证据段 rank6/50）。
- 延迟（20 样本稳定值）：`P50 930.5ms / P95 1008.2ms`（首调含 ONNX 构建 2568.5ms；稳定态 820–1050ms）——贴 `P95 ≤ 1000ms` 预算，本次复跑超 ~8ms。
- 真检索读数（warmup 后）：query「华雄是孙坚杀的吗」`rerank={enabled:true, window:20, considered:20, skippedPinned:0, applied:true, reason:null}`、`timing.rerank=819.0ms`；证据段 `0005:c0015` 由 rank6 跌出 top10。

## 根因（2026-09-28 排查定案）

- **与重排窗口 / 档位无关**：证据段 rank6 落在窗口 20 内、`considered=20` 全参与，窗口截断不是原因。
- 打分器（bge-reranker-base）对**拒答 / 否定型问句**存在系统性**词面偏好**：query 强词元「孙坚」把孙氏相关段（`0005:c0012` 祖茂、`0007:c0015`、`0006:c0015`、`0008:c0001`、`0108:c0012` 等）推入 top10，正确答案段「关羽斩华雄」因 query 无对应词面被降权跌出。
- 词面相关 ≠ 答案相关：打分器不区分「孙坚杀华雄」（错误前提）与「华雄被谁杀」（答案需求）；典故#1 的 `3→4` 属同类干扰。

## 影响

- 拒答 / 否定型问法答案质量下降；这类问法historically反复返工（bug-00021 / bug-00032 系列同根因：词面 vs 语义）。
- 启用态延迟贴线（P95 ≈ 1008ms），无余量。

## 现状与口径

- 本地 `.env` 为启用态；仓库默认仍 `off`（`.env` 不入库，契约见 `docs/feat-A018-event-table-interface.md` §5.5）。
- **`on` 仅代表「接入重排」，不等于 A030 验收通过**。
- 本票只登记状况与证据；不在本票顺手加规则。

## 待办（负责人拍板）

1. 取舍方向：① 接受为已知风险（重排仅正面 / 事件问法受益）；② 拒答 / 否定型问句豁免重排——须先有可靠判据（禁止新增 LLM 调用，只能用既有结构信号），并复评证明拒答#5 恢复、其余定点不倒车；③ 放弃启用。
2. 延迟：`P95 1008ms` 是否接受，或再收档（窗口 20→16 / batch / 线程）并跑更大样本（≥50 次）取稳定值。

## 验证方式

- 定点复评：`cd mcp-server/sango; node scripts/verify-rerank.mjs`（离线真实权重，不调 LLM API），落盘 `dev-docs/test/standard-set/results/feat-A030-rerank-fixedpoint.json`。
- 真链路读数：日志页「检索诊断」的 `rerank.*` 与 `timing.rerank`（判读见 `docs/troubleshooting.md` 步骤 6），sango 终端日志行 `[sango] 检索重排（阶段：…）`。
