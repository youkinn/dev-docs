## 证据（零 LLM，直连日志库 + LLM 明细）

llm_call_logs（stage=novel_boundary_check）请求体实证：

- 何进 trace：复核参考片段 = 第 2 回「何进大喜…众官皆退」段；而结论句后半「召外兵入京 / 终致事败身死」的依据在第 3 回所引片段（[片段5][片段6] 之一）。
- 孟德 trace：复核参考片段 = sanguo-yanyi:0004:c0012，原文止于「时吕布已牵马至阁外」；而结论句尾「托辞献刀 / 借试马之机逃去」在第 4 回 c0013。

两例复核参考都是「结论句所引多片段里的其中一个」，单片段天然撑不住整句。

## 根因

复核参考片段只取一个：citation.ts 的 findLowOverlapSentences 对带指针句，在结论句自己所列 [片段N] 中按字面重叠最高选一个作参考（citation.ts:579 → bestFragmentText），agent.ts:984 只把这一个片段文本交给 checkNovelBoundarySupport；复核 prompt 的判据也写成「该片段原文」支撑整句核心断言。

于是：生成轮做跨段合并叙述（事件类并池后「一段一事实」，跨段是常态）→ 单片段不足 → unsupported → 整句裁剪；复核预算=1（bug-00039），只有 bestOverlap 最高的唯一句走 LLM 复核，其余低重叠句直接裁 → 一句被裁往往整答无留存 → 拒答「演义中未涉及」。

## 影响面

演义域全部「生成轮结论跨多段、且挂多个指针」的问法；事件类（A018 L1/L2 并池）尤其集中。不涉及检索侧、不涉及事件表数据、不新增 LLM 调用次数。

## 修复口径（负责人 2026-10-10 拍板；Coco 定契约，小胡实现）

- **复核轮输入 = 结论句所引全部合法 [片段N] 的原文**，逐片段带各自的 〔出处N〕 结构化出处行（回号判据所需的结构化出处随片段一并给出）。
- **判据**：核心断言（人物 / 事件 / 结局 / 因果的事实归属）由所引片段整体支撑（任一片段或片段组合足以推出或印证）→ supported；所有所引片段都不足以支撑，或改动了片段中的人名 / 动作方向 / 受事者 / 结果 → unsupported。
- **边界口径**（除第 5 条外均为沿用现有契约，不在本票变更范围）：
  1. 触发条件不变：字面重叠 < 阈值（0.5）的待裁叙述句才进复核；
  2. 复核预算不变 = 1 次 LLM 调用（仅输入变长）→ 不新增调用，不触发原则 14/15 报备；
  3. 复核候选句仍取 bestOverlap 最高的唯一句；其余低重叠句沿用确定性裁剪（bug-00039 口径不变）；
  4. 无指针叙述句（模型未挂指针）无「所引片段」可言 → 沿用现口径（全注入片段取最高重叠那一个作参考）；
  5. 回号类问句的确定性短路（chapterConsistencyVerdict，0 LLM）保留，判据扩展为「结论回号与所引任一片段 〔出处N〕 行回号一致 → supported」；
  6. 所引指针全部不可解析 → 参考片段为空 → 沿用 unsupported、不调 LLM；
  7. 片段条数按结论句实际所指（链路上限 = 注入条数，实测 3–7），不额外裁剪；实现若判断需要硬上限，在交付摘要中给出建议值与理由。
