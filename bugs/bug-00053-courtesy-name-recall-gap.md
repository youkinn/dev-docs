## 根因

链路：检索侧池内排序 → 取窗（top10）→ 注入 → 生成轮 → 边界复核。

证据段在池内但排 11–18 名 → 不进注入窗 → 生成轮拿不到原文、只能靠先验知识作答 → 边界复核按「答案无片段支撑」判 unsupported（赵云 / 孙策，**行为符合护栏契约**）→ 落库「演义中未涉及」。张飞一题被复核放行（引用 `0065:c0007`，该段并无「字」断言，判 supported 属护栏宽松侧），故 4 题中仅它答对。

排序靠后的机制方向（**待逐条实测取证后再改，不凭推理动手**）：问句人名是连续二字（赵云），断言段原文是拆分并列（姓赵，名云，字子龙）→ 人名 bigram 词面不重叠；问句的「字」又与全书大量「某字某」表述段（周瑜字公瑾 / 朱治字君理 / 董袭字元代…）同词面 → 排序被稀释。
