# bug-00008：召回评测口径缺陷（字面匹配对「概括型答案」失效，A 类读数虚高）

> Bug 号：bug-00008
> 状态：待修复
> 关联特性：feat-A004
> 涉及项目：dev-docs（评测基建 `test/recall-classify-900.mjs`）
> 登记：Coco ／ 发现：Coco（2400 问复验） ／ 登记日期：2026-09-19
> 关联：bug-00003（A 类范围被本条污染）／bug-00007（评测集内容质量）
> 复现：`node --experimental-strip-types dev-docs/test/recall-classify-900.mjs --json test/cls2400.json`

## 现象：分类器读数与人工抽检严重不符

2400 问全量复验时，A 类（检索漏召）读数经不起交叉检验：

| 检验口径 | 结论 |
|---|---|
| 分类器（答案字面 2-gram 匹配） | A 类 **1082 题（45.1%）** |
| A 类中「答案字面全库无落点」 | **361 题（33.4%）** |
| A 类中含人物的题（445）→ 人物所在段在 top3 | **412 题（93%）**，未进 top5 **0 题** |
| 概括型问句专项（359 题）→ 源段已进注入视图 | **212 题（59.1%）**，但分类器只判 **34 题（9.5%）OK** |

**即：A 类里混进了大量「源段已召回、模型看得见、只是答案不是原文表述」的题。**

## 根因：判定口径是「字面」，而答案常是「现代白话概括」

分类器用「参考答案的字面 2-gram 覆盖率 ≥ 0.5」判定答案是否可见。新增题库（②③ 段）的参考答案大量是现代概括，毛本并无此串：

| 问句 | 参考答案 | 毛本实际写法 | 字面 |
|---|---|---|---|
| 华雄是怎么死的 | 被关羽所杀 | 「云长……斩于马下」 | ✗ |
| 曹操献刀指的是什么事件 | 曹操借王允七星宝刀刺杀董卓 | 「操有宝刀一口，献上恩相」（且分属两段） | ✗ |
| 曹昂是怎么死的 | 宛城之战中为救曹操战死 | 救父而死（无「宛城之战」字样） | ✗ |
| 糜夫人是怎么死的 | 长坂坡之战中投井 | 投井而死（无「长坂坡之战」字样） | ✗ |

实测 `被关羽所杀`、`为关羽所杀`、`被曹操所杀`、`被孙权逼死`、`宛城之战`、`中箭而死` 在毛本 **df = 0**；毛本写「遂斩」「斩之」「斩于马下」。

另：概括型答案常需 **2 段以上**（如「曹操献刀」= 献刀段 + 刺杀段），单段字面匹配天然判不出。

## 影响面（**直接影响 bug-00003 的验收标准**）

1. **bug-00003 的验收目标「A 类清零」不可达**——A 类里 ≥361 题不是检索缺陷，改检索代码永远清不掉。
2. **修复方向可能被带偏**：若为凑 A 类指标去调检索，会为「答案非原文表述」的题过度优化，反而伤害真实召回。
3. **读数不可比**：同一系统在 900 问 / 2400 问下的 A 类占比（34.6% → 45.1%）差异，主要来自题库口径变化，不是系统退化。

## 判定口径定稿（2026-09-19 负责人拍板）

**判对 = 证据段进 top3，且注入视图可见。表述差异不算错。**

| 项 | 定稿 |
|---|---|
| 主判据 | **证据段是否召回**（该题对应的事实段，在不在 top3 且注入可见） |
| 参考答案的用途 | **降级为「定位实体的线索」**（走 `alias.json` 提人物/地名），**禁止**做字面逐字对标 |
| 禁止 | 用参考答案去反推原文；用字面覆盖率当「答对/答错」的判据 |
| 表述差异 | **算对**：证据段召回「云长……斩于马下」，参考答案写「被关羽所杀」→ **对** |
| 字面口径保留范围 | **仅引语型答案**（答案本身即原文，如 `不求同年同月同日生`）作下界 |

**已知偏差（两端）**：
- **假阴**（长答案）：`被关羽所杀` 在毛本 df=0 → 误判为「检索漏召」
- **假阳**（短答案）：2 字答案覆盖率非 0 即 1 → 段内偶然出现即判「可见」

**证据段的认定**：不能只靠字符串（`华雄`+`斩` 会把「潘凤又被华雄斩了」误认为华雄之死，方向反了）。须结合**实体共现 + 事件动词**，并以人工金标校准。

**校准要求**：抽 200 题分层建金标集，人工标「该题证据段是哪几段」，作为唯一可信裁判。

## 修复要求

1. 分类器 A 类**拆分双读数**：
   - **A1 字面可拼齐** → 真·检索漏召（当前 **721 题，66.6%**）
   - **A2 字面全库无落点** → 口径待判（当前 **361 题，33.4%**）
2. 增加**实体命中口径**（答案人物 / 关键实体是否已在注入视图），与字面口径**并行输出**，禁止互相替代。
3. **验收口径修订**：bug-00003 目标改为「**A1 清零**」；A2 另议（并入 bug-00007 评测集整改，或单列为「概括型作答能力」需求）。
4. 引用读数必须标注口径（字面 / 实体），禁止混用。

## 验收（测试即文档）

- 分类器输出 A1/A2 双读数，且 **A1 + A2 = A**。
- 概括型问句（359 题）同时给出「字面 OK 率」与「源段可见率」两个数。
- 2400 问复跑，A1 与实体口径的差集可逐题列出。
