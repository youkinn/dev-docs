# bug-00058 A018 事件/典故表 chunkIds 漏段（gold 不完整）致事件类 hit@5 失真

- 特性：feat-A018（事件表 + 事件名桥）｜涉及项目：dev-docs（定位脚本 / 评测集，主）、mcp-server（events.json / allusions.json 数据）
- 状态：已修复
- 发现场景：story-A018-03 提测，快照 `test/standard-set/events/results-standard-name/feat-A018-2026-10-12-165435.json` 中 `L1#E01201`（三让徐州）hit@5=0

## 现象

事件类评测 hit@5 偏低且与语义不符：问「三让徐州」时检索能召回正确证据段，但 gold 未覆盖，判 miss。

## 判据

评测 gold = `events.json` / `allusions.json` 行的 `chunkIds`；`hit@5` = 检索 top5 与 gold 的交集。gold 漏段 → 命中率虚低（非检索问题）。

## 根因（定位口径）

`test/events/build-events.mjs` 段位定位：只在 `test/events/first-pass.md` 登记的**回号范围**内，用关键词（事件名 + 实体词 + 2-gram）匹配。两类漏段：

1. **登记缺跨回**：事件情节跨两回，first-pass 登记为单回 → 另一回不参与定位。
2. **同回关键词漏段**：关键词字面不在某段 → 同回内也会漏（如「凤仪亭」三字不在该场景描写段）。
