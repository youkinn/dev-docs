## 现象与根因

- 裸回号（`N回：` 无「第」）→ 解析器漏收该回号 `chapterRefs` → 该锚按「无回号」处理、不限回，存在跨回误命中风险：地名#3 / 地名#10 / 战役#9 / 问法归一#7 / 数字称谓#7 / 事件关系#1 / 事件关系#8 / 死亡#1。

- 零引号锚（`第73回` 无原文片段）→ 三条匹配路全空、恒不计分：官职#7。
