## 根因（双因，任一缺口修掉该现象即消失）

1. **检索漏召**：`0081:c0002`（张飞封赏段）该 query 排 #55。其 cosine 0.581 高于多数 top10 段，缺在 bm25Norm 0.594 + **无标签分**——标签体系六类事件（战役 / 人物之生 / 人物之死 / 谋略计策 / 政治事件 / 结盟外交）不含官职/封号，「政治事件」判定标准还明确排除「普通官职升降」，第三路召回对该类问句结构性无覆盖。
2. **护栏结构洞**：结构门第三条只校验「带 [片段N] 的叙述句」。模型把指针写在引文句（`[片段5] 玄德既为汉中王…`，与片段 100% 重叠），结论句无指针 → 整句跳过重叠门与边界语义复核 → 引用不支撑也放行。`llm=1` 即实证：本应触发复核的断言零调用。
