## 现象

问「刘备登基后，张飞被封为什么」，答「刘备登基后，张飞被封为车骑将军、领司隶校尉，进封西乡侯。」并引用 0073:c0003（进位汉中王表文，含「臣昔与车骑将军董承」）。答案事实本身正确——第 81 回原文「迁张飞为车骑将军，领司隶校尉，封西乡侯，兼阆中牧」在语料有载——但**引用不支撑结论**：注入片段全是张飞战斗 / 登场类，被引片段里张飞仅以「五虎大将」身份出现、车骑将军属董承，司隶校尉 / 西乡侯在片段中完全无载。

trace：`4d7a408a-995a-4b47-bacc-3bbc8a8c120a`，`llm=1`（护栏零复核调用，答案断言从未被校验）。

## 根因（双因，任一缺口修掉该现象即消失）

1. **检索漏召**：`0081:c0002`（张飞封赏段）该 query 原排 #55。余弦 0.581 高于多数 top10 段，缺在 bm25Norm 0.594 + **无标签分**——标签体系六类事件不含官职/封号，「政治事件」判定标准还明确排除「普通官职升降」，第三路召回对该类问句结构性无覆盖。
2. **护栏结构洞**：结构门第三条只校验「带 [片段N] 的叙述句」。模型把指针写在引文句（与片段 100% 重叠），结论句无指针 → 整句跳过重叠门与边界语义复核 → 引用不支撑也放行。`llm=1` 即实证：本应触发复核的断言零调用。
