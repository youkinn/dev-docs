## 现象

traceId `7269df08-1115-48ca-b6a9-f2f16fe8adca`：

```text
POST /api/chat  {"message":"严颜义释张飞","domain":"sango-novel"}
→ 200 {"answer":"严颜感张飞恩义乃降，即“义释严颜”之事。…（含 ch63/ch64 原文引用）"}
```

「严颜义释张飞」是**主宾反转 / 错误前提**：演义原文只有「张飞义释严颜」（第 63 回），没有「严颜义释张飞」这一情节。系统把问句当「张飞义释严颜」作答，**顺着错误前提给出貌似正确的解读**，用户无法分辨前提已被反转。

期望（按 feat-A004 契约）：原文没有该情节 → 回「演义中未涉及」；「纠正前提」（提示正确的是张飞义释严颜）是新能力，超出「只解读不评论」契约。

## 判定（依需求文档）

- feat-A004 验收核心＝**拒答**：原文没有的必须答「演义中未涉及」，禁止先验补全；非目标＝不做 query 改写。
- 「严颜义释张飞」这一情节原文不存在 → 按契约应拒答；现状顺着字面命中「义释严颜」语段照答 → **答非所问，是缺陷**。
- 设计文档已预告此形态：`docs/sango-classics-rag-research.md` §5.1 A2 三态判定——模型「拒绝接受错误前提」时会主动纠正，恰好撞「不做评论」红线，需显式观察。

## 根因（机制读数）

1. **检索三途径对「主宾反转」无判别力**：`严颜义释张飞` 与 `张飞义释严颜` 字集 / bigram 完全一致 → BM25 词袋等价、bge-m3 cosine 相近（0.630 高），label「义释严颜」命中直接把 63 回语段钉在 top1（finalScore 0.836 高置信）。判对判错全由字面重合决定，**无实体角色对齐**——与 bug-00022 已定结论「保字面但含义变」同族。
2. **生成轮无前提校验**：注入片段全为义释严颜内容，prompt 无「问句谓词关系与原文相反 / 原文无此情节 → 未涉及」规则；模型直接照答。结论句事实正确（严颜感张飞恩义乃降），但未回应题意 → 误导性顺答。
3. **向量召回同样无判别力**（本 trace cosine 高）→ 「换向量召回」不能作为修复方案。
