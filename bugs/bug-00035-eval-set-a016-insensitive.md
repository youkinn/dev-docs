- `test/standard-set/feat-A015-verify.mjs`（68 行）= 纯薄壳：POST `http://127.0.0.1:8787/dev/benchmark/run`，打印服务端 summary，**无任何硬编码判定 / 固定通过率**（文件头注释与 story-A015-02 契约：判定逻辑收敛到 mcp-server `sango/src/benchmark/` 单模块，禁止两份实现漂移）。
- 服务端 `runner.ts` 逐题 `index.search(question, 50)` + 证据锚判定（rank 1–5=top5，6–10=tail，其余 miss），每跑是真重跑。

## 根因

1. **基准集 v0.1 无 A016 归一化覆盖题（主因）**：`docs/sango-rag-regression-benchmark_v0.1.md` 110 题（11 类）没有「问法归一类」——所有问题要么直接用规范形词面（夏侯惇被箭射中哪只眼睛 / 口吐鲜血），要么是元语言问法（“目”指什么 / “口”指什么）。A016 的 query 改写（左目→左眼、口→嘴 等）在基准上**一次都不被触发**，归一化修得再好通过率也不会变 —— 60.0% 恒定是「测不到」而非「没效果」。
2. **归一化在基准上生效但判分不敏感**：实测 110 题中 **23 题 query 被改写**（座次见下），其中 10 题 top10 候选集合不同；但双侧（query 与语料）同口径扩张，多数题 rank 结构不变，通过率不变。合法改写样例：数字称谓#1 五虎大将→五虎上将、官职/爵位#10 首级→头、人物#9 卧龙/伏龙→诸葛亮；损坏改写样例（bug-00036）：地名#3/#8、拒答#4 长坂坡→长坂坡坡，典故#1 温酒斩华雄→温酒温酒斩华雄，典故#5 草船借箭→草船草船借箭，数字称谓#3 桃园三结义→桃园桃园结义，身体部位#6 口吐鲜血→嘴血，拒答#10 方天画戟→方天方天画戟 等。
3. **「命中大幅回升」解释**：语料侧 fragmentOnly / 别名双写确实提升了召回（A016 目标），但基准 110 题不覆盖这些差异点，回升体现在 A016 验收定点题（3/5/6），不体现在基准汇总。

## 修复口径（Coco 定案）

1. **基准集 v0.1 新增「问法归一」类目（6–8 题）**，全部以验收定点为锚、llm 无关：
   - 左目 / 左眼（夏侯惇左目被射，验收 3 锚：0018:c0014）
   - 右目 / 右眼（关羽刮骨 右臂侧，验收 3 同族）
   - 过五关斩六将 / 五关斩六将（第 27 回回目锚，验收 5 同源，bug-00003 漏召背景）
   - 死亡白话问法（死的时候多少岁 / 享年 / 卒年，验收 6 同族）
   - 器物方位（器官方位限定词，验收 3 同族）
   - 口吐鲜血 → 嘴（身体部位白话语义题）
   - 每题给「证据锚 + 判定标准」，纳入 parser 类别表（parser.ts CATEGORIES 增「问法归一」）。
2. **verify.mjs 补类别显示名**：`CATEGORY_LABEL` 增 问法归一 → 问法归一（与基准集小节标题同口径）。
3. **与 bug-00036 一并重跑**：修复后全量重跑基准，新增类目全部 top5 命中；旧 110 题对照无回退（与 2026-09-26-1045 快照逐题比对）。
4. **防重演**：A016 统计脚本（换说法差异清单）与基准集覆盖要对账——统计清单产出的换说法差异关键案例必须能落到基准某题（验收 1 的「≥3 类型实际案例」同时是基准覆盖探针）。

## 验证方式

- 基准重跑：新增「问法归一」类目 6–8 题通过率 100%（top5 全命中）；旧 110 题逐题对照 1045 快照无回退。
- 归一化开 / 关对比：关闭 rewriteKeys（仅片段侧）时新增类目题应出现 miss，证明该类目真的在测归一化（对判分敏感）。
- 与 bug-00036 修复同批验证：损坏改写清零后，基准 23 题改写中的损坏形态消失、合法改写保留。
