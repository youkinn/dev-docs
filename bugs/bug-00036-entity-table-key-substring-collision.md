## 根因（机制层 + 数据层）

1. **机制层缺「邻接延伸检查」**：`normalize` 对改写键做全局最长匹配替换，不检查键命中位置能否延伸为表内已知更长词（canonical / aliases / rewriteKeys）。键是 canonical 真子串时，canonical 原文必被扩张（键匹配 canonical 前缀/中部/词尾，replace 后叠加尾/首）。
2. **数据层放入 34 个真子串键**：表起草时按「缩略词 / 茎词」收录（博望、长坂、赤兔、玉玺、木牛、流马、就计、苦肉、画戟、蛇矛…），未校验「键 ⊆ canonical」的包含关系。
3. **2026-09-25 审查记录判据反了**：`docs/sango-entity-normalization.md` §全类别审查记录「缩略词实测量安全保留（玉玺 28 次全为传国玉玺语境）/ 茎词独立 0 次安全保留」——「全含于长词」恰是**必扩张条件**而非安全保留条件（玉玺⊂传国玉玺 ⇒ 传国玉玺→传国传国玉玺）。该判据需修正为「键含于更长表内词 ⇒ 禁作改写键，仅可作片段侧素材（或按延伸检查保留）」。

## 影响

- 语料索引与 query 双侧同口径扩张，多数题检索结果不变（掩盖层），但：索引文本含垃圾词（赤兔马马 23 处等），查原文 / 引用展示会露馅；部分题有意向差异（基准 110 题 23 题 query 被改写、其中 10 题 top10 集合不同，见 bug-00035）。
- 「口吐鲜血→嘴血、首级→头」等合法改写在基准上生效（数字称谓#1、官职/爵位#10 等），说明 60.0% 恒定不是归一化不生效，而是判分条件下不改变结果（bug-00035）。

## 修复口径（Coco 定案，非降级方案）

1. **机制层 · 邻接延伸检查**：替换前检查「键 + 邻接字符能否延伸为表内已知词（canonical / aliases / rewriteKeys）」，能延伸则不替换。目标行为：长坂坡 不扩张（长坂 命中但邻接「坡」延伸为长坂坡），博望之战 照常改写（博望 独立语境）。
2. **数据层 · 34 键逐键裁决**：合规则（表内独立指称、无歧义）保留并依赖延伸检查兜底；不合规键（玉玺、赤兔、木牛、流马、就计…）从 rewriteKeys 移出、按需转 fragmentOnly 片段侧素材；登场行「出仕/出山」或式 canonical 一并规范。
3. **校验层 · §8 增检查**：`rewriteKeys` 不得是 canonical 真子串（含 canonical 时告警 + 剔键，与现有 K1/K2 同类处理）；加载后对全表做一次 canonical 子串审计跑批并在启动日志/测试断言体现。
4. **文档层**：`docs/sango-entity-normalization.md` 补「键排斥规则：rewriteKeys 不得是表内任何 canonical 的真子串」；修正 2026-09-25 审查记录「安全保留」判据。
5. **回归**：A016 验收 3/5/6 重跑 + 基准对照（与 bug-00035 一并），断言修复前后受损词 0 扩张。
