## 链路核对（工具出参 → 注入 → 答案，两例一致暴露「片段不足仍作答」）

### 例 1（马超）
| 环节 | 读数 |
|------|------|
| 工具 | `sango/sango_novel_search`，`caller=server` / `stage=fastpath`，`args={"query":"马超投靠刘备后，后来如何了","limit":10}`，88 ms，success |
| 检索诊断 | `query.normalized=马超投靠玄德后，后来如何了`；funnel：lexical 2344 → vector 50 → label 107 → merged 2344 → `topN=10` → `injected=6` → `cited=1` |
| 注入 6 段 | 全部在 ch65 / ch57 / ch58（葭萌关战张飞、马腾衣带诏、兴兵雪恨）——**都在「投靠刘备」前后，无一处讲结局** |
| 答案支撑片段 | ch73「封关羽、张飞、赵云、马超、黄忠为五虎大将」rank7=0.723 **未注入**；ch91「马孟起病故」**未进候选**；ch92 马超坟 |
| 生成轮 | 1 条 generation：prompt 1940 / completion 23，finish=stop，回复 `…[片段4]`（= ch57 衣带诏段），模型选它做引用 |
| 结论 | 答案本身有原文支撑（ch73/91/92）但检索未送达；模型凭先验答对 + 挂一条语义无关引用 |

### 例 2（夏侯渊）
| 环节 | 读数 |
|------|------|
| 工具 | `sango/sango_novel_search`，fastpath，`args={"query":"夏侯渊字什么","limit":10}`，success |

| 结论 | 演义原文没有该信息 → 契约应拒答；模型凭史实先验答出「妙才」+ 挂一条只含夏侯惇字的引用 |

## 定性（口径以需求文档为准）

| 出处 | 口径 |
|------|------|
| `requirements/feat-A004-sango-classics-rag.md:9` | 拒答是验收核心：原文没有的必须答「演义中未涉及」，禁止先验补全 |
| 演义域生成轮 system prompt 第 3 条（trace 内实测存在） | 片段中确实没有相关内容时回复「演义中未涉及」，禁止用先验知识补全 |

事实核对：例 2 演义原文确实没有夏侯渊的字 → 正解「演义中未涉及」；例 1 原文有答案片段（ch73/91/92）但未注入 → 模型凭先验答对。
**是缺陷**：两例均为「注入片段不足以支撑结论，未触发拒答，凭先验作答 + 挂不支撑结论的引用」，违反 A004 拒答红线；例 1 另叠加「有答案未送达」（召回暴露面）。

## 根因

三层，主因在生成轮约束服从性（编排层）：

1. **主因 · 生成轮先验作答（约束在、模型不服从）**：演义域提示词已含「禁止先验补全 + 无内容回未涉及」（bug-00021 复盘已确认原著域提示词完整），本次实测证明**约束存在但不被遵守**——与 bug-00021 修前的「约束缺失」是不同根因面。模型在片段不足时仍用世界知识作答，并把不相关片段挂为引用，`success` 直返，接口与正常回答不可区分。
2. **暴露 · 检索/注入未送达答案片段（例 1）**：ch73 五虎将段 rank7=0.723 未注入（topN=10 截断），ch91 病故段未进 top20——答案在原文、工具没送到生成轮（同 bug-00003 / bug-00006 注入窗口族）。
3. **暴露 · alias 归一化揉坏问句 + 原文无信息（例 2）**："夏侯渊字什么" → "妙才字什么"，检索全扑向 ch71「妙才（才略）」段；且无论归一化与否，演义原文都没有「字妙才」——本例本质是「演义无此信息，应拒答」。

## 证据读数

- 例 1：funnel `injected=6/10`、`cited=1`；答案支撑段（ch73 rank7=0.723）未注入；引用 ch57 与结论语义无关。
- 例 2：funnel `injected=8/10`、`cited=1`；归一化 query `妙才字什么`；全语料「字妙才」0 命中。
- 生成轮两例均 finish=stop、status=success，无失败 / 拒答标记。
