# bug-00040：边界复核把引语片段句逐句纳入复核，带引文答案多 1~2 次 LLM 调用（响应时间较 A016 前翻倍）

> 登记：Coco／报告：负责人（2026-09-26 三条 trace 追问「为什么多次 LLM 调用」）／登记日期：2026-09-26

## 现象

A016 护栏链路上线后接口响应时间翻倍：原先快路径（sango-novel）极限 1 次生成（~1.8s），现在 typical 2~4 次 LLM 调用、server 2.4~6.2s。负责人实测三条 trace（2026-09-26 18:04~18:06，上限落地后）：

| trace | 调用 | server | 明细 |
|-------|------|--------|------|
| bbb110f9（孙权遣人向关羽求亲） | 4 次 | 6206ms | gen 2628 + judge×3（1514/914/1051） |
| 4f08d60f（夏侯惇左眼） | 2 次 | 2432ms | gen 1381 + judge 981 |
| e1bfb360（张飞封侯） | 2 次 | 2472ms | gen 1449 + judge 924 |

注：2 次≠「分类+生成」，快路径无分类；是「生成+复核」。

## 根因

1. a121557（bug-00032/33/34 共因修复）把低重叠句从确定性裁剪改为「逐句 LLM 语义复核」：复核 1 句 = 1 次 judge（~0.9~1.5s）。bug-00039 的 MAX_BOUNDARY_REVIEWS=3 只封极端（无封顶），**不降典型成本**。
2. 低重叠候选混入了引语片段句：模型输出引文行（如 `[Q19]“……！……！……”`）被 splitAnswerSentences 按句末标点切分，[Qn] 指针只挂在首段，后续引语句变成「无指针叙述句」，逃过 [Qn] 豁免分支；而重叠归一化（normalizeOverlapText）**剔除引号内容** → 整句引语 grams 为空 → 必判低重叠 → 逐句进复核。bbb110f9 答案 1 结论句 + 2 引语句 = 3 次复核（引语恰好占满上限）。
3. 引语句复核无信息增益：整句即片段原文、渲染端独立处理，verdict 不影响最终成文（bbb110f9 两句引文最终都保留在答案里）；judge 参考片段（无指针句取全片段最高重叠）还常配到无关段（judge#3/#4 参考片段是吕蒙/陆逊段，与「立斩汝首」无关）——纯浪费调用，白付 ~2.4s。

## 修复口径（Coco 定案方向，小胡实现）

1. **引语片段句豁免复核（主修）**：重叠归一化后无有效 gram 的句子（整句内容均为引语）不进复核候选、不占复核预算、不裁剪。带引文答案降到 1 次 judge（仅改述结论句）。
2. **无指针句复核参考片段修正**：引语句被豁免后，剩余无指针句仍取全片段最高重叠——若最高重叠片段与句意无关，复核参考失真；按句-片段重叠显式相关才给参考，否则按无参考（unsupported 倾向）处理。实现时评估，避免引入误裁。
3. **复核预算 = 1（负责人 2026-09-26 预算原则）**：单请求至多复核 1 个低重叠句（bestOverlap 最高者），其余候选直接按 unsupported 裁剪；总调用 = 指定域 ≤ 生成 1 + 复核 1 = 2 次，自由模型（auto）≤ 分类 + 生成 + 复核 = 3 次（负责人明确，走快路径一般 2 次），响应 ~2.4~3.4s 内。
4. 验证：A004 ㉔~㉘ 更新断言（㉘ 上限断言 3→1）+ 新增负例（答案含引文行 → 0 次引文 judge；judge 次数=低重叠叙述句数，预算 ≤1）+ 全量回归。
