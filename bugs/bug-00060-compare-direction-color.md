# bug-00060 评测台历史快照比较：方向与配色（当前快照恒在左、delta = 当前 − 目标）＋ 弹框开合抖动

- 特性：feat-A015（历史快照比较）｜涉及项目：mcp-web
- 状态：已修复
- 复现（负责人实测 2026-10-13）：查看快照 `feat-A015-2026-10-13-1038`，点历史行「比较」→ 弹框显示 战役 `通过 9 → 10（+1，绿）`、`未命中 8 → 7（−1，红）`；另报弹框打开后再关闭页面抖动。

## 现象与机制

- 两侧数据：1038（当前快照）战役 通过 9 / 兜底 3 / 未命中 8；1015（目标）通过 10 / 兜底 3 / 未命中 7。
- 原实现 delta = 目标 − 当前（`utils/benchmarkCompare.ts` 类别 delta = `cb − ca`），于是「当前快照的通过数比目标少 1」被显示成 `+1` 并标绿，与负责人规则（当前快照与目标相比、正数绿 / 负数红）整号相反；`通过` 与 `未命中` 两列同源同错，`兜底` 两侧相等（3 → 3）看不出差异。
- 数值本身无误：1038 通过 163 / 战役 通过 9，1015 通过 165 / 战役 通过 10，是 bug-00059 判分限回（消掉 战役#10 rank=11 的过判）的预期结果，非回归。

## 修复口径（负责人 2026-10-13 定）

- 弹框两侧固定：**左 = 当前快照**（评测台页顶「当前快照」那一次），**右 = 目标**（下拉选择的历史快照）。
- 计数差值（总计行 / 类别表 / 组集桶）：**delta = 当前 − 目标**，以当前快照为观察主体；并排的「当前值 → 目标值」只表示两侧取值，不表示差值方向，**当前值加粗**便于分清左右。
- meta 行只留「当前快照 <时间> → 目标 <时间>」；runId 只在顶部选择条展示，不放 meta 行。
- delta 配色：**大于 0 绿、小于 0 红**（按符号，不按好坏语义）；0 不着色 —— 故 `未命中` 增多（正数）按符号显绿，是符号口径的必然结果。
- 文案：「基准 / 对照」改为「当前快照 <时间>」/「目标 <时间>」；行内列名 `A 名次 / B 名次` 改为 `当前快照 名次 / 目标 名次`，操作列 A / B 按钮提示同步；逐项表表头 `white-space: nowrap` + 名次列加宽（112 / 132），表头不换行。
- 目标默认项 = 点「比较」的那一行；该行 == 当前快照（或题量不一致）时回退候选首条（沿用原 candidates 口径）。
- 范围：仅 mcp-web；后端与比较数据口径（id / rank / status / 类别计数）不变；仍只比题量一致的快照。
- 逐项名次表「变化」标签同样按当前快照主体（同源同错，一并翻）：`up` = 当前名次比目标更靠前（rankA < rankB）、`down` = 当前更靠后、`enter` = 当前在榜 / 目标未召回、`leave` = 当前未召回 / 目标在榜、`flat` = 一致（含两侧都未召回）；「排名上升 / 排名下降」筛选计数随之同口径。

## 弹框开合抖动（同票修）

- 根因（真浏览器实测）：`BenchmarkCompareModal.vue` 自行锁背景滚动（打开时 `document.body.style.overflow = 'hidden'`、关闭恢复）。`style.less` 已用 `html body { overflow-y: visible !important; width: auto !important }` 中和 antd 自带滚动锁（bug-00017）、槽位交给 `html { overflow-y: auto; scrollbar-gutter: stable }`（bug-00011）；自加的内联 `overflow: hidden` 把 body 变成内部滚动容器、文档滚动被换走 —— 页面纵向滚动条连同预留槽位一起消失，视口宽 +15px，居中内容右移 7.5px，即开 / 关两个瞬间各抖一次。
- 修法：删除自加滚动锁，背景不滚动交给 `style.less` 既有两条兜住（`.ant-modal-wrap { overscroll-behavior: contain }` 阻断滚轮链式穿透 + 槽位常驻不抖）。

## 实测读数（真 Chrome 1440 视口，脚本 `_pw-core/a060-jitter.js`、`a060-compare.js`）

- 抖动：修前 打开后 `headerX 60.4 → 52.8`、`clientWidth 1425 → 1440`、滚动条 15 → 0，关闭回 60.4；修后 开 / 关全程 `headerX 60.4`、`clientWidth 1425`、滚动条 15 不变。
- 滚轮穿透无回归：弹框打开时在遮罩上连滚 6 档，`window.scrollY 573 → 573`。
- 比较展示：`战役 | 通过 9 → 10（−1）| 兜底 3 → 3（0）| 未命中 8 → 7（+1）`（当前值 9 / 3 / 8 加粗），meta 行 `当前快照 2026-10-13 10:38 → 目标 2026-10-13 10:15`。
- 表头不换行：逐项表 6 个表头（含「当前快照 名次」112px）与组集逐项表 7 个表头（含「当前快照 首段名次」132px）实测均单行（`getClientRects().length = 1`）。
- 行级变化：`典故#12「煮酒论英雄」中曹操认为天下英雄是谁` 当前名次 3 / 目标名次 1 → `↓ 下降`（原显示 `↑ 上升`）；同批 `排名上升（0） / 排名下降（7）`（该快照判分收紧后当前名次全部不比目标靠前）。

## 验证方式

- 单测：`src/utils/benchmarkCompare.test.ts` 覆盖方向（A = 当前、B = 目标）、`delta = 当前 − 目标`、行级变化主体（up / down / enter / leave 与筛选并入）、配色映射（正绿负红、0 无色）。
- 真浏览器 + 真快照：查看 1038 → 对 1015 点比较 → 左为当前快照 1038、右为目标 1015；战役 通过 9 → 10（−1 红）、兜底 3 → 3（0 无色）、未命中 8 → 7（+1 绿）。
- 抖动：真浏览器复测弹框开合前后页不位移（读数见上）。
