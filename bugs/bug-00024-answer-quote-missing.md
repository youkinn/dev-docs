# bug-00024：同题两次请求答案渲染不一致（一条 answer 只有角标 ¹ ²、无引语正文）

> Bug 号：bug-00024
> 状态：修复中（2026-09-24 负责人拍板：候选 1 + 候选 2 同做、与 bug-00025 合流一起修；指派 小胡 单人合流）
> 关联特性：feat-A006（答案展示结构化：结论 + 引用出处卡片）
> 涉及项目：mcp-orchestrator（生成轮答案组装 / 提示词约束）
> 登记：Coco ／ 报告：负责人 ／ 登记日期：2026-09-23
> 关联背景：feat-A013 需求讨论中复核 trace 时发现；A013 缓存上线后同题会锁首次答案，「答案本身渲染不稳」是独立缺陷，与本票不冲突

## 现象

同一问题「三英战吕布」（`domain=sango-novel`，`route_source=label`）21:45 内两次请求，`answer` 展示不一致：

| traceId | 时间 | answer | citations |
|---------|------|--------|-----------|
| `5018ace0-fb37-44a0-a6bc-5150cdff1bca` | 21:45:21 | 261 字：结论 + ¹ 引语正文 + ² 引语正文 | 2 条 |
| `932d36fc-9510-40e9-875d-03c758f7f79f` | 21:45:27 | 36 字：结论 + ¹ ² 角标，**无引语正文** | 2 条（与上相同） |

两条 `citations` 完全一致；差异只在 `answer` 是否内联引语正文。

## 判定（依需求文档）

feat-A006 接口契约：`answer` = 结论正文；`[Qn]` 指针替换为渲染引语「引文」+ 全局角标；`[片段N]` 叙述段**只渲染上标角标、不内联原文**；并约定「`answer` 自洽可独立成读，旧前端忽略 `citations` 不受影响」。

36 字那条：模型把「引语引用」输出成裸 `[片段3] [片段4]`（无正文），渲染层按契约对 `[片段N]` 只渲染角标 → 结论段出现裸角标 ¹ ²、无内联引文 → **不满足「answer 自洽可独立成读」**，且同题两次展示不一致 → 是缺陷。

## 链路核对（生成轮读数）

| traceId | 生成轮 `response_summary`（deepseek-v4-flash-0731，`finish=stop`） |
|---------|--------------------------------------------------------------------|
| `5018ace0` | `结论\n[片段3] 吕布见了，弃了公孙瓒…\n[片段4] 吕布荡开阵角…`（`[片段N]` 后自带引语正文） |
| `932d36fc` | `结论\n\n[片段3] [片段4]`（`[片段N]` 后无正文） |

检索 / 注入 / citations 两 trace 完全一致；差异仅生成轮输出形态。两次模型均使用 `[片段N]` 指针（而非 `[Qn]` 引语指针）。

## 根因要点（分层）

1. **生成侧输出抖动（直接原因）**：同输入同提示，模型两轮对 `[片段N]` 是否内联引语正文不一致——提示词未强制「引用必须有正文」。
2. **渲染层无兜底（放大原因）**：按 A006 契约 `[片段N]` 只渲染角标；裸指针照契约产裸角标，无「指针后无正文 → 内联 `citations` 对应片段」兜底。
3. 非检索问题：两 trace 检索 / 注入 / citations 完全一致。

## 修复口径（2026-09-24 负责人拍板：候选 1 + 候选 2 同做，与 bug-00025 合流）

- 候选 1（提示词层）：生成提示强制「引语只输出 `[Qn]`；`[片段N]` 后必须紧跟正文」，禁止裸指针。
- 候选 2（渲染层兜底）：`[片段N]` 指针后无内联正文时，服务端自动以 `citations` 对应片段原文补全（「原文」+ 全局角标，与 `[Qn]` 同形态），保证 answer 自洽可独立成读。
- 指派：小胡 单人合流（提示词 + 渲染兜底同做；渲染落点 `citation.ts` 按项目分工归小胡，与 bug-00025 共用同一渲染出口）。

## 验证口径（修复后）

- 同题反复提问（如「三英战吕布」），answer 恒含引语正文（或恒有渲染兜底），无裸角标。
- 负例不回归：无引用问题 `citations=[]` 行为不变。

## 复测打回与口径修订（2026-09-24）

修复后负责人复测 trace `595ce8a5-b7c4-460b-b8a4-90d52eb559fa`（「三英战吕布」）打回：生成轮仍输出裸指针 `[片段3][片段4]`（无正文），首版兜底把两段片段**全文**内联进 answer（约 680 字、第 2 段含古风诗全篇），与 citations 卡片全文重复 → 「回答变成很长的一串」。

修订口径：兜底不再内联全文，改为内联**片段开头短摘**（≤40 字、按「。！？；」整句切分、截断附「…」），answer 短而自洽（对齐 5018ace0 好样本量级），全文仍由 citations 卡片承载；提示词同步补「[片段N] 后紧跟一句简短正文（≤40 字）、禁止大段抄写」（防模型走抄写长文路径，与 bug-00025 同源）。
- 验证口径补充：answer 不内联片段全文，裸指针兜底每段短摘 ≤ ~40 字，与卡片原文不重复。
