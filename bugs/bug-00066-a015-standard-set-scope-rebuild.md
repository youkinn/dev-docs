# bug-00066 A015 标准集口径不合规（史名战役题 + 需归纳题）

## 现象

A015 标准集（`docs/sango-rag-regression-benchmark_v0.1.md`）与「只收录答案在原文可直接检索到、无争议的题」口径不符，混入两类题：

- **战役类 20 题**：答案多为「官渡之战 / 赤壁之战」这类史名，原文无此字样，整类不可搜。
- **需归纳 / 概括题 30 条**：事件关系 18（「为什么 X」需跨段归纳因果）、数字称谓 10（「三顾」是几次、「五丈原」是地名还是尺寸 等）、典故 2。

后果：判分把「题本身不可搜」算成「检索缺口」，整改方向失真。

## 修复口径（契约）

- A015 只收录答案在原文可直接检索到、无争议的题（白纸黑字型：名 / 字 / 号 / 地名 / 器物名 / 回号等）；需归纳 / 概括的题一律移出，后续并入事件集（事件有完整上下文，可解因果 / 概括），专项归 **feat-A021**。
- 战役类 20 题整类删除，不做补充。
- 移出归纳题 30 条：事件关系 18、数字称谓 10、典故 2（清单见 `docs/a015-benchmark-gap-routing.md` §3）。
- 补白纸黑字题 13 条：事件关系 +10、典故 +3，逐条对语料核锚。
- 死亡类补 1：典韦之死（补 bug-00052 删除的 #10 空位，不动其余行顺序）。
- 全表按类别连续重编号（各类 1..N、无空号）；题量 235 → 199、类数 12 → 11。
- 解析侧无契约变化：`mcp-server/sango/src/benchmark/parser.ts` 按 `## 类别` 标题名匹配（剔除「一、」等编号前缀后匹配类别名），删类 / 改编号不影响解析；证据列格式与表头列序不变。

## 验证方式

- 结构：各类表格行数合计 = 199、11 类，各类编号 1..N 连续；文档头部「总题量」与「回归测试结果」表合计一致。
- 题集现状、移出清单与分派见 `docs/a015-benchmark-gap-routing.md`。
- 以新题集重跑 `test/standard-set/feat-A015-verify.mjs` 出新快照，段级 / 回级通过率按 199 题重算；旧 235 题读数（快照 `test/standard-set/results/feat-A015-2026-10-13-1444.json`）作废。
