# bug-00025：演义域答案内联服务端内部编号 ⟨Qn⟩（模型抄写注入片段 + 渲染层未剥离）

> Bug 号：bug-00025
> 状态：待修复（仅登记，未分配；承接时按本票「修复口径」节走）
> 关联特性：feat-A006（答案展示结构化：结论 + 引用出处卡片）
> 涉及项目：mcp-orchestrator（生成轮答案组装 / 提示词约束 / 引用渲染兜底）
> 登记：Coco ／ 报告：负责人 ／ 登记日期：2026-09-23

## 现象

`/api/chat` 问「孙尚香后来怎么样了」（`domain=sango-novel`，`route_source=label`），`answer` 正文出现服务端内部编号 `⟨Q6⟩`～`⟨Q15⟩`：

- traceId：`20117022-82bd-441d-a126-6f677cfdfbf4`，`status=success`，`server` 7.7s
- answer 片段：`…权曰：⟨Q6⟩“母亲何故烦恼？”国太曰：⟨Q7⟩“你直如此将我看承得如无物！…`（共 10 个编号）
- 同一响应 `citations` 干净（无 `⟨Qn⟩`），引用卡片正常

## 判定（依需求文档）

feat-A006 接口契约（`requirements/feat-A006-citation-display.md`）：`answer` = 结论正文，服务端把模型输出 `[Qn]` 指针替换为渲染引语 + 全局角标；`[片段N]` 叙述段指针**只渲染上标角标、不内联原文**。`⟨Qn⟩` 是注入视图内部编号（A004 spec §6.3 服务端引用定位标记），不属于用户可见内容 → 出现在 `answer` 即违反契约 → 缺陷。

## 链路核对（生成轮读数）

| 环节 | 内容 |
|------|------|
| 注入视图（LLM 请求内） | `[片段2] 少顷，孙权入后堂见母亲。国太捶胸大哭。权曰：⟨Q6⟩“母亲何故烦恼？”…`（服务端给每处引语编号 `⟨Qn⟩`） |
| 生成轮原始输出（deepseek-v4-flash-0731，`finish=stop`，390 token） | `结论\n\n[片段2] 少顷，孙权…权曰：⟨Q6⟩“母亲何故烦恼？”…默然无语。`（模型用 `[片段2]` 指针并**整段抄写**，含 `⟨Qn⟩`） |
| citations（工具原文） | 干净，无 `⟨Qn⟩`，与注入视图同源 |
| 落库 answer | `结论\n\n¹ 少顷，孙权…⟨Q6⟩…`（`[片段2]` 被渲染为角标 `¹`，抄写文本中的 `⟨Qn⟩` 原样保留） |

## 根因要点（分层）

1. **生成侧（直接触发）**：模型未遵守「引语只输出 `[Qn]`、不得抄写」（A011 提示词第 2 条），把 `[片段N]` 指针 + 整段原文（含服务端编号）夹带输出。模型对 `[片段N]` 指针形态输出不稳定，与 bug-00024 同源（00024 = 裸指针缺正文，本票 = 夹带抄写）。
2. **渲染层无兜底（放大 / 必现面）**：
   - H4 长引语安全网 `stripOverlongModelQuotes` 只匹配直角引号 `「…」`（`/「([^」]*)」/`），本次抄写使用弯引号 `“…”`（75 字超长引语）→ 违规抄写未被识别丢弃；
   - `renderAnswerWithCitations` 只处理 `[Qn]` / `[片段N]` 指针，未剥离 / 还原抄写文本中的 `⟨Qn⟩` 内部编号 → 必现给用户。

## 修复口径（2026-09-23 已定：A+B 同做）

- 候选 A（渲染层兜底，已采纳，老陈）：最终 `answer` 输出前剥离未被消费的 `⟨Qn⟩` 内部编号（保留引语正文，去标记），保证 `answer` 无内部标记、可独立成读；H4 安全网扩展识别弯引号 `“…”` 形态（与语料引号记号一致），超长抄写整段丢弃走兜底。
- 候选 B（提示词层，已采纳，小胡）：加固「引用只输出 `[Qn]`、严禁夹带正文 / 输出 `⟨Qn⟩`」，作为生成侧约束，与候选 A 不互斥。
> 指派：待负责人安排（候选 A 渲染兜底 → 老陈；候选 B 提示词 → 小胡）。
- 与 bug-00024 同根因族，修复须合流：00024 候选 2（`[片段N]` 裸指针时补 citations 内联）与本票兜底共用同一渲染出口，保证任意模型输出形态下 `answer` 恒无内部标记、可独立成读。
