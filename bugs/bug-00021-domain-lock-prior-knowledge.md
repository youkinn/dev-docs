## 现象

```
POST /api/chat  {"message":"玄德是谁的字","domain":"fengyunsanguo"}
→ 200 {"code":200,"data":{"answer":"刘备","citations":[]},"message":""}
```

traceId `a5232947-e012-4c9d-9dfe-5a76c7abb0c6`（`log_type=chat`、`status=success`、`response_code=200`）。

负责人判据：`fengyunsanguo_query` 出参不是「刘备」，答案由大模型给出 —— 但接口层面与题库答案**无法区分**：`status=success`、`citations=[]`，用户看不出这是模型先验知识。

## 链路核对（工具出参与模型输出不一致）

| 环节 | 读数 |
|------|------|
| 路由 | `domain=fengyunsanguo` → 域锁定快路径，正常命中并预调工具 |
| 工具 | `fengyunsanguo_query`，`args={"text":"玄德是谁的字"}`，`caller=server` / `stage=fastpath`，耗时 2 ms，`status=success` |
| 工具出参 | `1. 关公坐骑赤兔马原本是谁的坐骑？ → 吕布`（**与问题不相关**） |
| 生成轮 | 1 条 `llm_call_logs`：`stage=generation`、`prompt_tokens=109`、`completion_tokens=1`、`finish_reason=stop`、`response_summary=[{"type":"text","text":"刘备"}]` |
| 注入 | `request_summary` 第 3 段 system = 上述候选（候选确实进了上下文，模型仍无视） |

结论：路由与工具调用都正常，**答案不在候选内**，来自模型自身先验知识。

## 定性（口径以需求文档为准）

| 出处 | 口径 |
|------|------|
| `requirements/feat-A003-model-tool-routing.md:48` 验收 3 | 语义指向三国但题库未收录 → 固定回复「题库未收录该题，请换个问法」，**不使用题库外知识作答** |
| `requirements/feat-A011-prompt-slimming.md:141` | 题库域：命中只输出答案原文；**未命中**只回「题库未收录该题，请换个问法」 |

事实核对（题库 88 题）：含 16 道「XX 的字是什么」，**无「刘备的字」**（刘备相关 6 题均不问字）→ 本问句属「题库未收录」，正解是未收录话术。

即：**是缺陷**（违反 feat-A003 验收 3）。feat-A011 §141 的「未命中」包含「候选不相关」，实现把它窄化成「候选为空」一种情形 —— 属语义收窄。

## 根因

两层，主因在编排层（唯一能兜住全部情形的一环）；召回层是暴露条件，不是可修点。

1. **主因 · 编排层提示词收窄**（`mcp-orchestrator/src/agent.ts:123` `FENGYUNSANGUO_DOMAIN_PROMPT`）
   feat-A011 瘦身（提交 `ec4cfcb`）把旧版两条约束删掉，新版只写「候选为『未召回到任何候选题目』时只回复『题库未收录该题，请换个问法』」→ **只覆盖候选为空**。候选存在但不相关时，生成轮没有任何约束 → 自由作答。
   被删的旧版约束（main 上仍在，A011 分支已删）：`UNIFIED_SYSTEM_PROMPT` 能力二第 4 条「候选中没有含义对应的题目时（包括只是字面相似、含义不同的），只回复『题库未收录该题，请换个问法』」、第 5 条「禁止使用题库之外的知识作答、补充或改写答案」，以及分域兜底「三国题库域」条。
2. **次因 · 召回层无门限**（`mcp-server/fengyunsanguo/src/fengyunsanguo-service.ts:291` `candidates()`）
   纯字符 bigram 的 Dice 系数，`filter(score > 0)` 后取 topN，默认 `limit=1` → **永不给空候选**。本问句与赤兔马题共享 `是谁` / `谁的` 两个字组，dice 0.235 排第一。契约本意即「只负责捞候选，是否含义对应由 LLM 判定」。

## 为什么不能靠召回门限修（重要）

- 「玄德是谁的字」0.235 可被门限（如 0.3）拦掉 → 空候选 → 模型回「题库未收录该题」。**能修掉第一现场，但不彻底。**
- 「刘备的字是什么？」top1 = **0.667**（「吕布的字是什么？」），**高于真命中「张飞字什么」0.400** —— 问法同模板（题库有 16 道「XX 的字是什么」），任何安全门限都拦不住；此时模型仍会自由作答。
- 故：相关性判定必须归 LLM（契约本意），门限只能作半程加固，不能替代提示词修复。

## 影响面

- 触发面：题库域生成轮（域锁定快路径 + auto 分类编号 2），凡「题库未收录、却被召回不相关候选」的问句。
- 严重度：**重大** —— 域锁定被绕过。用户拿到的是模型先验答案，却以 `200 success` + `citations=[]` 返回，与题库答案不可区分；本次「刘备」恰好正确属巧合，**错误答案同样会被当成功返回**。
- 仅 A011 分支复现：main 上旧提示词含约束，同问句会回未收录话术 → 属 A011 提测验收打回项。
