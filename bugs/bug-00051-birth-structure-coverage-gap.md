## 根因：两层枚举不全

1. **登场标签缺口**：`birthByPerson` 由标签「人物之生-X登场」派生（`sango-index.ts` 加载期），实测 136 个人名；9 人里 **孙权 / 鲁肃 / 陆逊 / 张郃 无该标签**（tags/event.json 实测：曹操 / 吕布 / 张辽 / 华雄 / 典韦 有）→ 结构路无入口，首次出现段全靠 BM25 / 向量，实测 4 问全部落榜。
   - 顺带：**陆逊连「人物之死-陆逊之死」也没有**（9 人中唯一双缺），死亡类问法同样无结构路入口（另列待核，不在本次补录）。
2. **词表缺口**：`sango/src/search/intent.ts` 的 `BIRTH_GATE = /(出场|登场|出世|现身|出现)/` 未收「露面」→ 华雄「初次露面」不进结构路（词面召回已兜住，但保证区置顶缺位）。

## 影响面

所有「X 首次 / 初次 / 最早 + 登场 / 出场 / 露面 / 出现」问法（「被提及」不属本口径，见修复口径 1）；覆盖上限取决于登场标签覆盖面（实测 136 人）。

## 修复口径（负责人 2026-09-29 拍板）

1. 口径收口：登场意图**只认「第一次出场」语义**（首次出现 / 登场 / 露面）；**不收「被提及」**（「首次被提及」是另一语义，不进本机制）。
2. 标签补录（老陈，走 A018 缺口回流 `test/events/gap.md`，批次补录）：补 4 条「人物之生-X登场」后 `birthByPerson` 自动带上，检索侧零改动；陆逊「之死」标签缺口另列待核，不在本次补录。
   - 同类：bug-00043（tags 死亡 / 登场标签 3 处事实 / 回号错误，源数据待修）不在本次范围。
3. 词表（老陈）：`BIRTH_GATE` 并「露面」（出现 / 现身同义）；**不新增**「提及 / 首见」，单测锁定「首次被提及」不触发登场意图。
4. 批次：挂 feat-A018，与 bug-00004 复核放行一起随本特性提测 / 上线（负责人 09-29）；分支 = mcp-server `chen/feat-A018_event-table`。
5. 答案出口不属本票：曹操 / 吕布 / 张辽 召回已到位但用户仍看到「演义中未涉及」——复核侧误裁，见 bug-00004 补充节。
