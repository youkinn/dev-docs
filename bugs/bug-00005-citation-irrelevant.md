负责人实测中，「引用原文」多次与结论无关或毫无信息量：

| 问句 | 结论 | 引用的原文 | 问题 |
|---|---|---|---|
| 关羽的武器叫什么 | 关羽的武器是青龙刀 | 「我在此等候多时了！」（第42回） | 与武器无关 |
| 关羽 过五关斩六将 | 关羽过五关斩六将… | 「五关斩将之时，还能记否？」（第50回）+「四散摆开。」（第50回） | 前者是曹操在华容道重提旧事，后者 5 字无信息量；**事件本身的叙述在第27回** |

## 根因（四条叠加）

### 1. `quotes[]` 只收引号内文本 —— 叙述型答案指针引不到（结构性）

构建期 `quotes[]` 从 chunk 内**成对引语**（`“…”`）抽取。但《三国演义》里大量答案是**叙述句**，根本不带引号：

| 问句 | 答案句 | 是否引号内 | 指针能否引到 |
|---|---|---|---|
| 张飞的武器叫什么 | 张飞造丈八点钢矛（第1回） | ❌ 叙述 | ❌ |
| 关羽的武器叫什么 | 云长造青龙偃月刀（第1回） | ❌ 叙述 | ❌ |
| 诸葛亮死于第几回 | 孔明奄然归天（第104回） | ❌ 叙述 | ❌ |
| 关羽过五关斩六将 | 六将阻关（第27回） | ❌ 叙述 | ❌ |

实测 11 例中 **4 例的答案句不在 `quotes[]` 内**（第 3、5、6、9 例；第 1 例的答案句「姓徐，名晃，字公明」在引语内，属可引）。此时该段可用引语只剩无关对话——第 1 回段 `0001:c0011` 的引语表只有一条 `Q1(3字)：冷艳锯`。

**结论：指针通道（`[Qn]` → `quotes[]` → 服务端渲染）对「叙述型答案」结构性失效。**

### 2. 指针校验强制非空 —— 模型被迫凑一条引语

`mcp-orchestrator/src/citation.ts` 的 `validateQuotePointers`：

```ts
return { ok: pointers.length > 0 && invalid.length === 0, pointers, invalid };
```

`pointers.length > 0` 是硬条件。答案若以叙述句为主、段内无可引用的引语，模型**必须**凑一个 `[Qn]` 才能通过校验，否则整条答案被打回兜底。凑出来的就是「我在此等候多时了！」这类无关引语。**这不是模型不忠实，是校验规则把它逼到了这一步。**

### 3. 引语表无信息量下限 —— 短引语照当「引用原文」

全库 8937 条引语的长度分布：

| 阈值 | 条数 | 占比 |
|---|---|---|
| ≤ 3 字 | 134 | 1.5% |
| ≤ 5 字 | 738 | 8.3% |
| ≤ 8 字 | 1694 | **19.0%** |
| p50 | 17 字 | — |

「四散摆开。」「冷艳锯」「不知。」这类被当作「引用原文」渲染给用户，撑不起任何结论。

### 4. 召回排序 + 无引用相关性闸门 —— 无关跨回片段进答案（2026-09-24 补）

「三英战吕布」样本：ch19「下邳城 / 白门楼」片段靠词面「吕布」多次 + 无关 label「谋略/计策-陈登间吕布」加成被排到 #1（finalScore 0.77 > 真相关 ch5 0.768）；top-6 保底全注入、模型引用其引语 `[Q3]`、Guard 人物集合校验放行 → 无关引语必现。与根因 1–3（叙述型被逼凑引语）不同入口：本层是**召回排序偏差 + 引用相关性校验缺失**，召回正确时同样会犯（关联 bug-00003）。

## 影响面

- **叙述型答案全覆盖**：器物、制度、时间、因果类问句的答案多为叙述句（「XX 造 XX」「XX 死于 XX」），是原著解读的常见问型。
- 与 bug-00003 叠加：召回漏时模型只能在无关片段里凑引语（第 6/9 例即是），**引用质量进一步恶化**；召回对时也会凑（第 11 例），故本条独立成立。

## 修复要求（**需负责人拍板方向**）

| 方案 | 做法 | 代价 |
|---|---|---|
| A. 指针可省 | 允许「无引语可引」时不出指针，改为输出结论 + 出处 | 改动最小；但 §6.3「引用原文由字段渲染」的强制力下降 |
| B. 叙述句入引用表 | 构建期新增「关键叙述句」候选（如含「造」「字」「死于」的陈述句），与引语同表供指针引用 | 需**重建语料**（触碰「只重建一次」原则，见 `sango-corpus-spec.md` §9） |
| C. 引用表加下限 + 允许多引 | 引语表设信息量下限（如 ≥8 字），且允许「0 指针」作为合法态；同时禁止模型凑指针 | 改动中等，需同步改校验与 prompt |
| D. 召回排序纠偏（2026-09-24 补） | label 命中加成审查 / query 相关度加权，防无关跨回片段登顶（关联 bug-00003，mcp-server） | 需回归排序评测口径 |
| E. 引语↔问题相关性闸门（2026-09-24 补） | 渲染前校验被引片段与 query 相关性（词面 / 分数阈值），不满足丢弃该指针走兜底（mcp-orchestrator） | 需定阈值与负例防误杀 |

**Coco 建议方案 C + A 组合**：短期先做 A（允许 0 指针，解掉「被迫凑引语」这一条），B 视语料重建窗口一并处理。**B 若采纳，须与本期其他重建项同批，避免二次重建。**

2026-09-24 补充：D 属 mcp-server（关联 bug-00003）、E 属 mcp-orchestrator，与 A/B/C 不相斥；「三英战吕布」样本即 D+E 双缺的实况，方向待负责人拍板。

## 验收（测试即文档）

- 叙述型答案不再出现无关引语：「关羽的武器叫什么」不得引「我在此等候多时了！」。
- 无引语可引时，输出结论 + 出处，不得硬凑指针。
- 短引语（≤8 字）不得单独作为「引用原文」渲染。
- 有正确引语时优先引正确的那条：「诸葛亮与诸葛均是什么关系」须引「某乃卧龙之弟诸葛均也…」，不得附「愿闻此人姓名。」。
- 问「三英战吕布」不得出现第 19 回「陈登间吕布」无关引语（2026-09-24 样本）。
- 探针附注 E 应消失。
